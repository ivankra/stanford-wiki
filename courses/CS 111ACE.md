# CS 111ACE: Problem Solving Lab for CS111

The ACE section for [CS 111](CS%20111.md), and the one that publishes most: every Spring 2026 session's deck is online, and three of them ship their section code as a public GitHub repository.

## Materials

This quarter's site publishes its syllabus and puts everything else behind Stanford login: its Materials and Admin pages both redirect there. [Spring 2026](https://web.stanford.edu/class/archive/cs/cs111ace/cs111ace.1266/) is still up and open, with a deck for every session, and the section code stays public on GitHub.

- **Syllabus**: this quarter's [syllabus page](https://web.stanford.edu/class/archive/cs/cs111ace/cs111ace.1272/syllabus/) — Tuesdays and Thursdays 9:30-10:20 in Lathrop 299, office hours, the three-part [CS 111](CS%20111.md) outline and the grading rules — "adapted from the policies in previous CS111ACE offerings".
- **Slides**: this quarter's are under `restricted/materials/`, behind Stanford login. [Spring 2026](https://web.stanford.edu/class/archive/cs/cs111ace/cs111ace.1266/lectures/spr26/1-welcome-and-processes-and-threads.pdf) published a deck for each of its eight sessions, 1.8 MB apiece, and those still open.
- **Notes**, **Solutions**, **Videos**: nothing found, this quarter or any other.
- **Assignments**: none — the sections work problems in the room.
- **Exams**, **Projects**: none.
- **Repo**: [cs111ace-section-code](https://github.com/cs111ace/cs111ace-section-code), the organization's one repository, for the scheduling, linking and memory sessions.

## Syllabus

Eight Tuesday sessions, shadowing [CS 111](CS%20111.md) but in its own order: processes and threads, concurrency, scheduling and linking, dynamic and virtual memory, paging with midterm review, the clock algorithm, filesystems, crash recovery.

## Prerequisites

- Concurrent enrollment in [CS 111](CS%20111.md), and the instructor's consent. [CS 111](CS%20111.md)'s own announcements describe the application and permission-number route into ACE.
