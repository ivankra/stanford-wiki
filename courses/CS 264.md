# CS 264: Beyond Worst-Case Analysis

Built on the observation that worst-case bounds often rank the wrong algorithm first: each unit swaps in a different model — smoothed inputs, stable instances, planted structure, predictions — and asks what can still be proved. Follows Roughgarden's book, which Stanford licenses electronically; four homeworks and a project.

## Materials

## Syllabus

16 lectures ([schedule](https://vitercik.github.io/bwca/schedule/)) in nine blocks: motivating examples and instance optimality (caching, linear programming, clustering); instance optimality in computational geometry; resource augmentation and online paging; parameterized algorithms and condition numbers; perturbation stability for clustering; spectral algorithms for planted bisection and planted clique; semi-random models and semidefinite programming; nonnegative matrix factorization; random-order models; smoothed analysis; automated algorithm configuration; and algorithms with predictions. The last sessions are project presentations.
