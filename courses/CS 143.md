# CS 143: Compilers

The course is organized around one artefact: a compiler for Cool, a small object-oriented language, built over five programming assignments from lexer to code generator.

## Materials

Everything a reader needs to follow the course is public: decks, both assignment tracks, the written-assignment solutions, the Cool documentation and three years of exams.

- **Syllabus**: the [dated schedule](https://web.stanford.edu/class/cs143/syllabus.html), with each PA and WA keyed to the lecture that assigns it.
- **Slides**: [seventeen decks](https://web.stanford.edu/class/cs143/lectures/lecture01.pdf) from Course Overview to Automatic Memory Management; lecture 18, "JIT Compilers and Fast Compilation", is listed with no file.
- **Notes**: the [Cool reference manual](https://web.stanford.edu/class/cs143/materials/cool-manual.pdf), a tour of the support code, the Cool runtime document and the SPIM manual.
- **Videos**: recordings are not posted.
- **Assignments**: [PA1–PA5](https://web.stanford.edu/class/cs143/handouts/PA1.pdf) and WA1–WA4, each written assignment with a LaTeX template.
- **Solutions**: [all four written assignments](https://web.stanford.edu/class/cs143/handouts/WA1sol.pdf). None for the programming assignments.
- **Exams**: [2024 and 2025 midterms and finals with solutions](https://web.stanford.edu/class/cs143/finals/final-2025sol.pdf); for 2026 the solutions are posted but not the papers.
- **Projects**: none — the compiler is the assignment sequence.
- **Code**: the Cool support code, documented in the tour; work happens on `myth.stanford.edu`.

## Syllabus

From the [posted schedule](https://web.stanford.edu/class/cs143/syllabus.html), eighteen lectures over ten weeks:

1. **Front end** (lectures 1–8): course overview, Cool as the project, lexical analysis and finite automata, introduction to parsing, syntax-directed translation, top-down parsing, bottom-up parsing in two parts.
2. **Semantics** (lectures 9–13): semantic analysis and type checking in two parts, runtime organization, code generation, operational semantics. An in-class midterm falls on 30 April, between lectures 9 and 10.
3. **Back end** (lectures 14–18): local optimization, global optimization, register allocation, garbage collection, and a final session on JIT compilation.

PA1–PA4 track the front end through code generation; PA5, an optimizer, is due on the last day of classes.

## Prerequisites

- Discrete mathematics and proofwriting: [CS 103](CS%20103.md) or CS 103B.
- Systems programming in C: [CS 107](CS%20107.md) or equivalent. The catalog also allows consent of instructor in place of either.
