# CS 358A: Programming Language Foundations

The formal-systems course behind Patrignani's secure-compilation work: calculi first, then type systems chosen for what they prove about security — non-interference, robust safety, ownership, session discipline — and the proof machinery, ending at logical relations and semantic models. The catalog hedges the list with "possible systems of study", so the selection varies by offering.

## Syllabus

From the catalog description, identical in both offerings; no public syllabus. Possible systems of study:

1. The lambda calculus and System F.
2. The Pi and Spi calculi.
3. Simply-typed languages.
4. Security type systems for non-interference, and robust safety.
5. Linear types and ownership types.
6. Session types.
7. Logical relations and semantic models.

Alongside the systems, the techniques for reasoning formally about them.
