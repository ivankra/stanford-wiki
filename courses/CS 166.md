# CS 166: Advanced Data Structures

The instructor states the goal as design rather than catalog: "after each topic, you feel as though you yourself could have invented the data structures we explored." Implementations are in C++, chosen for bit manipulation and abstraction in one language.

## Syllabus

The [lecture list](https://web.stanford.edu/class/archive/cs/cs166/cs166.1266/) runs nineteen sessions, each topic taking one or two:

1. **Queries over static structures**: range minimum queries (two lectures), succinct rank queries, succinct select queries.
2. **Approximation and randomness**: hashing and sketching (two lectures).
3. **Trees**: balanced trees (two lectures), random binary search trees, better-than-balanced BSTs, splay trees.
4. **Amortization and heaps**: amortized analysis, binomial heaps, Fibonacci heaps.
5. **Hashing, again**: cuckoo hashing, cuckoo filters, peeling algorithms (two lectures).
6. **Dynamic connectivity**: disjoint-set forests.

The syllabus names the techniques these share — the Method of Four Russians, isometries, amortized analysis — and the applications they target: "maintaining connectivity information in a changing graph, locating points in 2D space, approximating the number of items in a set".
