# CS 106L: Standard C++ Programming Laboratory

One unit alongside [CS 106B](CS%20106B.md), spent on the language rather than the algorithms: what C++ actually does with initialization, templates, lambdas and moves, up to C++26. Sixteen lectures, no exams, and the quarter ends in week 8.

## Materials

The decks are the instruction for a course that does not record, and the assignments sit in a public GitHub repository with the autograder that marks them; only the in-class activities and submission need a login.

- **Syllabus**: the [landing page](https://cs106l.stanford.edu/) carries the dated sixteen-lecture schedule, and a separate [policies page](https://web.stanford.edu/class/archive/cs/cs106l/cs106l.1272/policies/) covers attendance, grading and the honor code.
- **Slides**: one PDF per lecture from the schedule — [Welcome](https://web.stanford.edu/class/archive/cs/cs106l/cs106l.1272/lectures/2026Fall-01-Welcome.pdf), Types & Structs and Initialization & References so far, with the rest posted as the quarter runs.
- **Notes**: no lecture notes — the decks carry the material. The one written handout is ["A Guide for Transitioning from Python to C++"](https://docs.google.com/document/d/1Y6r7U8Bz2sqAiV23kKpUS5uXQkga32X3ZFasHoKyq_8), which opens without an account.
- **Videos**: none — the policies page says lectures are not recorded, and points students at the slides instead.
- **Assignments**: [assignment 1, EnrollmentNavigator](https://github.com/cs106l/cs106l-assignments/blob/main/assignment1/README.md), was pushed to the public repository on 2026-09-27; the second is still to come. The seven weekly assignments Spring 2026 set are all there too. The 14 in-class activities, attendance codes and submission stay on [106l.com](https://www.106l.com/), behind a login.
- **Solutions**: none published; the autograder reports pass or fail rather than showing the answer.
- **Exams**, **Projects**: none. Passing is the activities plus the assignments, graded S/NC.
- **Repo**: the [assignments repository](https://github.com/cs106l/cs106l-assignments) carries every assignment's starter code and the Python autograder that students run on their own machine, after a setup assignment that installs the toolchain. Spring 2026's [lecture code](https://github.com/cs106l/cs106l-lecture-code) — one directory per lecture — is public as well.
- **Older offerings**: nineteen of the twenty archived quarters still serve their own schedule and decks, back to [Winter 2020](https://web.stanford.edu/class/archive/cs/cs106l/cs106l.1204/), whose 3.4 MB course reader is the fullest set of notes the course has ever published. The [`lectures/`](https://web.stanford.edu/class/archive/cs/cs106l/cs106l.1262/lectures/) directory is browsable on all of them even where the page links only two decks.
- **Textbook**: a free [online C++ textbook](https://cs106l.github.io/textbook/) written for the course, which says its material "can be used without reference to any of CS106L's course materials". Winter and Spring 2025 keyed their lectures to it; this offering links it nowhere.

## Syllabus

Sixteen Tuesday/Thursday lectures, finishing in week 8:

1. **Weeks 1–2, the basics rebuilt**: types and structs, initialization and references, streams.
2. **Weeks 3–4, the standard library and classes**: containers, iterators and pointers, classes, class templates and const correctness.
3. **Weeks 5–6, generic and operator programming**: function templates, functions and lambdas, operator overloading, special member functions.
4. **Weeks 7–8, resource management**: move semantics, `std::optional` and type safety, RAII, smart pointers and building C++ projects.

Passing requires all 14 in-class activities and both assignments; attendance is graded by a per-lecture code.

## Prerequisites

- C++ at the level of [CS 106B](CS%20106B.md) or CS 106X, which may be taken at the same time — the site invites "anyone that has learned or is learning programming fundamentals like functions and objects/classes".
