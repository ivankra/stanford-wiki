# CS 248B: Fundamentals of Computer Graphics: Animation and Simulation

An introduction to computer graphics through animation and physics simulation, built around five programming assignments (P0–P4, starting with a JavaScript and OpenProcessing warm-up). There are no exams.

## Materials

The schedule and the decks are public for this offering and for the 2 the course still hosts. The recordings are not, and neither is half the coursework: 2 of Autumn 2025's 4 project specs went to Canvas, and this offering has posted none yet.

- **Syllabus**: the [tentative schedule](https://stanford-cs248b.github.io/autumn26/) for all 18 lectures and a [course-info page](https://stanford-cs248b.github.io/autumn26/courseinfo.html) with the policies.
- **Slides**: 3 decks so far, as public Dropbox PDFs put up shortly before each class, on the [lectures page](https://stanford-cs248b.github.io/autumn26/lectures/index.html). [Autumn 2025's](https://stanford-cs248b.github.io/autumn25/) 18 and [Autumn 2022's](https://web.stanford.edu/class/cs248b/) 19 both stay public — the latter as slide-by-slide pages, each with a "Download slides as PDF" link, 1 to 43 MB apiece and about 270 MB in all.
- **Notes**: none. "There is no required textbook for CS248B", and the [resources page](https://stanford-cs248b.github.io/resources/index.html) that will collect reference material is still empty.

- **Repo**: the assignments build on a framework the course distributes to enrolled students; no public repository was found.

## Syllabus

From the Autumn 2026 schedule (19 lectures, marked tentative):

1. Particle systems and ODEs: forward/backward/midpoint/symplectic Euler, stability, stiffness
2. Particle collisions and collision detection (2 lectures)
3. Deformable models (3 lectures) and deformable collision processing
4. Fluids
5. Character modeling, forward and inverse kinematics
6. Interpolation and orientation
7. Rigid body simulation and constrained rigid body systems
8. Differentiable simulation and animation control; physics-based character animation; guest lecture

## Prerequisites

- Computer systems programming: [CS 107](CS%20107.md), computer organization and systems.
- Linear algebra: MATH 51.

## Related

- [CS 148](CS%20148.md): the introductory course before this one.
- [CS 248A](CS%20248A.md): the companion half, on rendering, geometry and images.
- [CS 348C](CS%20348C.md): graduate animation and simulation; this course is recommended before it.
- [CS 348E](CS%20348E.md): graduate character animation, taking this course's last unit (physics-based characters and control) further.
