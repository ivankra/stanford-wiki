# CS 331: Machine Learning for Algorithm Design

The 300-level seminar version of the argument [CS 225](CS%20225.md) makes at master's level: a solver rarely meets worst-case inputs, so the instance distribution is exploitable. Sessions alternate — a lecture supplying a tool (integer programming, GNNs, MDPs, learning theory), then a discussion class reading the papers that apply it, ending on algorithms with predictions. No homework; 60 points for discussion, 40 for a project.

## Materials

Open, and structured so the reading list stands on its own: every discussion session names its papers, linked to arXiv or NeurIPS.

- **Syllabus**: the [calendar](https://vitercik.github.io/ml4algs/calendar/) dates every session and marks it lecture or discussion, with the papers attached; the [home page](https://vitercik.github.io/ml4algs/) gives the format and the 60/40 grading split.
- **Slides**: fourteen [lecture decks](https://vitercik.github.io/ml4algs/assets/slides/lecture10.pdf). Discussion sessions have none by design.
- **Assignments and exams**: none — discussion and a project.
- **Projects**: the [brief](https://vitercik.github.io/ml4algs/project/) is public; student work isn't.

## Syllabus

[Sixteen sessions](https://vitercik.github.io/ml4algs/calendar/) from April 4.

1. Tools (Apr 4-13): a machine learning crash course, integer programming and SAT solvers, graph neural networks.
2. GNNs applied (Apr 18-27): GNNs for graph algorithms, a survey of GNNs for combinatorial optimization, algorithm configuration for IP and SAT, portfolio-based algorithm selection.
3. Sequential decisions (May 2-9): MDPs and RL, their combination with GNNs and integer programming, RL for combinatorial optimization.
4. Theory (May 18-30): theoretical machine learning, statistical guarantees and online algorithm configuration, then two sessions on algorithms with predictions.

Midterm project presentations fall on May 11.

## Prerequisites

- Algorithms: [CS 161](CS%20161.md) or equivalent. A machine learning course "is helpful but not required".
