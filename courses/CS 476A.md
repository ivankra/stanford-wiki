# CS 476A: Music, Computing, Design: The Art of Design

A CCRMA studio course on designing interactive musical software, tools, instruments, toys and games. Students build audiovisual programs in ChucK/ChuGL, write weekly reflections on the instructor's book *Artful Design*, critique each other's work in class, and design their own final project. AI tools are banned for doing the work.

The [course site](https://ccrma.stanford.edu/courses/256a-fall-2026/) is public and links the [syllabus](https://ccrma.stanford.edu/courses/256a/docs/256a-syllabus.pdf), the [reading schedule](https://ccrma.stanford.edu/courses/256a/docs/reading-responses.pdf) and [homework 1](https://ccrma.stanford.edu/wiki/256a-fall-2026/hw1) so far; submissions go to Canvas. ## Syllabus

Weekly readings follow the textbook, one chapter a week, alongside programming assignments:

1. Design is ____
2. Designing expressive toys
3. Visual design
4. Programming and sound design
5. Interface design
6. Game design
7. Social design
8. Manifesto

The site's topics: real-time software design for music (audio, graphics, interaction), audiovisual interactive programming, toolbuilding for creative expression, game and toy design for music, and a practical philosophy of shaping technology. The final project is a "design your own" interactive audiovisual software tool.

## Prerequisites

Programming experience in C/C++, Java, ChucK, Unity or Unreal Engine.
