# CS 369Z: Dynamic Data Structures for Graphs

Charikar and Monika Henzinger — whose work defines much of the area — on structures that answer questions about a graph while the graph is changing underneath them. The motivation the catalog gives is blunt: "With the increase of huge, dynamically changing data sets there is a raising need for dynamic data structures to represent and process them."
