# CS 104: Introduction to Essential Software Systems and Tools

An expanded version of the student-taught [CS 45](CS%2045.md), itself modeled on MIT's *The Missing Semester of Your CS Education*: the skills other courses teach in a hurried first week, given ten weeks of their own. Monday and Wednesday are lectures with live demos; Friday is an open-ended lab.

## Syllabus

From the [posted calendar](http://cs104.stanford.edu/), eighteen lectures and ten labs:

1. **Weeks 1–3, the shell**: system setup, shell and shell tools, data wrangling, shell scripting, text editors.
2. **Weeks 4–5, environment and network**: the command-line environment, networking.
3. **Weeks 5–6, versioning and building**: version control, version management, build systems and dev ops.
4. **Weeks 7–8, correctness and isolation**: build systems, debugging, security and cryptography, VMs and containers.
5. **Weeks 9–10, deployment and AI**: cloud and serverless, media and AI, AI tools.

Assignments follow the lectures by a week — "Shell We" on shell basics and regular expressions, "Bourne to be Wild" on scripting, "Off The Beaten Path" on networking and the path variable — with a short lab question set due each Friday.
