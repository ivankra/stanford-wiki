# CS 47: Cross-Platform Mobile Development

Two units, one afternoon a week, student-taught, and pitched on industrial evidence: React Native is "a primary tool for mobile development within Facebook, Instagram, Walmart, Tesla, UberEats, Coinbase, and SpaceX."

## Syllabus

From the [overview](https://web.stanford.edu/class/cs47/): "This course teaches the fundamentals of cross-platform mobile application development with a focus on the React Native framework (RN). The goal is to help students develop best practices in creating apps for both iOS and Android by using Javascript and existing web + mobile development paradigms."
