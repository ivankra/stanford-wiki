# CS 106A: Programming Methodology

The department's entry point: ten weeks of Python for students with no programming background, taught in lecture plus a mandatory weekly section led by one of the course's army of section leaders, with drop-in helper hours at the Lair.

## Materials

The syllabus, written lecture handouts and assignments are public, and the first assignments run on a public server that needs no account. Recordings are on Canvas.

- **Syllabus**: [topics, units, sections and helper hours](https://web.stanford.edu/class/cs106a/handouts_w2021/syllabus-cs106a.html). There is no dated week-by-week schedule.
- **Notes**: lectures are published as written handouts — [CS106A in a Picture](https://web.stanford.edu/class/cs106a/handouts_w2021/lecture-1-intro.html) and three more so far — and [Parlante's Python Guide](https://cs.stanford.edu/people/nick/py/) serves as the reference text.
- **Videos**: lectures are recorded, but the Panopto player is a Canvas tool.
- **Assignments**: [HW1 Bit](https://web.stanford.edu/class/cs106a/handouts_w2021/homework-1-bit.html), a set of small robot-on-a-grid problems restricted to the week's Python features.
- **Exams**: lecture 1 points at old final exams "linked off the course page", but no such link was there on 2026-09-27.
- **Projects**: none.
- **Code**: the [Bit exercises](https://codeinthebrowser.org/make/bithw/bit-alpha) run in the browser and save your work without a login; lecture examples are handed out as `.zip` files.

## Syllabus

The [syllabus](https://web.stanford.edu/class/cs106a/handouts_w2021/syllabus-cs106a.html) lists the course by topic rather than by week: types, numbers, strings, functions, lists, dictionaries, logic, decomposition, programming style, whole-program structure, text and file processing, debugging and performance, with lambdas, comprehensions and modules touched on at the end. Python's more advanced features are deliberately out of scope.

Work starts on a browser-based server with no install; PyCharm and a local Python 3 arrive in Week 2, when the mandatory sections also begin.

## Prerequisites

- None. The course assumes no programming background; students who already program are pointed at [CS 106AX](CS%20106AX.md) (same hour, accelerated) or [CS 193Q](CS%20193Q.md).
