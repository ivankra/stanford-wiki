# CS 329E: Machine Learning on Embedded Systems

A lab course built around a Raspberry Pi 5 on the desk: each week deploys something — an LLM, an image classifier, Whisper, a translation model — then makes it fit through quantization, LoRA or distillation. Half the grade is a project measured against its own proposal, with results weighted separately from the write-up.

## Materials

The class site and the lab repository are both public; nothing sits behind Stanford login.

- **Syllabus**: the [class site](https://ee292d.github.io/) carries the nine-week schedule of lecture and lab topics, the grading split (labs 40%, reading and participation 10%, project 50%) and the project deadlines.
- **Assignments**: the eight labs live in [github.com/ee292d/labs](https://github.com/ee292d/labs) — `lab0` (Pi setup) through `lab7` (understanding your data) — with notebooks, models and sample audio.
- **Code**: the same repository is the starter code.
- **Exams**: none; assessment is labs plus project.
- **Slides and recordings**: none posted.

## Syllabus

Nine weeks ([class site](https://ee292d.github.io/)): edge ML and ML frameworks, with Pi setup as lab 0; CNN and transformer architectures, running an LLM locally; training and fine-tuning — transfer and multi-task learning — with image classification and object location labs; data formats and model quantization, including quantization-aware training, alongside Whisper speech recognition and translation labs; PEFT (LoRA, adapters) and knowledge distillation, with a fine-tune-and-deploy lab; hardware for DNNs and how accelerator design shapes models; MLOps pipelines and observability; a guest lecture; then final project presentations.
