# CS 217: Hardware Accelerators for Machine Learning

Olukotun and Tambe's accelerator course, built around one loop repeated five times: take an architectural idea — a SIMD element, a vector unit, a global buffer with near-memory processing, an interconnect fabric — write it as a block in C++/SystemC, push it through high-level synthesis, and measure it on an AWS FPGA. The readings run from Kung's 1982 systolic-array paper to NVFP4 and BlockDialect, and the workloads are transformer inference as much as CNNs, so the recurring question is energy per token rather than peak FLOPs. Three of the last five sessions are industry talks: SambaNova, AWS Inferentia and Trainium, and NVIDIA.

## Syllabus

Ten weeks, per the [schedule sheet](https://docs.google.com/spreadsheets/d/1Aqpk1hEZD78bq0WoDe6edSs-tSC58hoEGCSJ6I--6KI/preview?gid=0).

1. **Weeks 1–2, arithmetic and efficiency**: introduction and high-level synthesis; data parallelism and efficiency metrics, read against MAGNet and Eyeriss; quantization, read against shared microexponents, NVFP4 and BlockDialect. Lab 0 covers the HLS and AWS FPGA flow; lab 1 is a SIMD processing element.
2. **Week 3, spatial compute**: systolic arrays, from Kung's 1982 paper to TPUv1 and TPUv4; vector and scalar units. Lab 2 is a vector processing unit.
3. **Week 4, data movement**: memory systems; interconnects and networks-on-chip, read against silicon-interposer NoCs and GPU interconnect evaluations. Lab 3 is a global buffer with a near-memory processor.
4. **Week 5, software**: two lectures on compilers and the software stack, read against DNN dataflow cost models, FlashAttention, PagedAttention and the PyTorch 2 compiler. Lab 4 assembles the accelerator top level with its interconnect fabric.
5. **Weeks 6–7, architectures**: project proposal reviews; GPU architectures; reconfigurable dataflow architectures, read against Plasticine.
6. **Weeks 8–10, frontiers and industry**: SambaNova's RDA (Raghu Prabhakar); two lectures on memory-centric and in-memory computing; AWS Inferentia and Trainium (Nafea Bshara); NVIDIA GPU architecture for AI (Ronny Krashinsky); then posters.

## Prerequisites

- Parallel computing or digital systems architecture: CS 149 or EE 180.
- Machine learning: [CS 229](CS%20229.md) is "ideal, but not required".

The labs assume enough C++ to write synthesizable SystemC; no prior FPGA experience is stated, and lab 0 is an orientation to the toolchain.
