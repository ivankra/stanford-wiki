# CS 147L: Cross-platform Mobile App Development

Three units of React Native beside the [CS 147](CS%20147.md) studio, taught by that course's co-lecturer: four "creative projects" — one of them "Build a tiny app for a very busy cat" — that take a single JavaScript codebase to both iOS and Android.

## Syllabus

The site's stated objectives are narrow and concrete: create a full-stack mobile application from scratch; build interfaces with TypeScript, React Native and CSS; understand the principles of cross-platform development.

What sets the course apart is how it is assessed. The primary instrument is **three 25-minute one-on-one coding interviews with a TA**, in weeks 5, 7 and 9, worth 45% together — "to assess your independent mobile development skills", with one redo allowed for an interview you do not pass. Practice exercises graded on completion carry 5%, creative projects 15%, participation 10%, and a group final project 25%. Work is marked on a bucket scale from ✓++ ("astounding work, above and beyond the expectations") down to –.

Two policies are worth quoting. Students taking [CS 147](CS%20147.md) concurrently may reuse that course's group project here, provided "you must contribute significantly to the development (programming) of the app". And on AI: generative tools "such as Claude Code or Cursor" are explicitly not forbidden, because "software developers are increasingly using them", but the staff warn they "can also inhibit the learning process by undermining the struggle and effort it takes to truly learn a new skill" and undertake to say week by week when to use them and when not.

Only weeks 1 and 2 have real topics so far — course logistics, then JavaScript, TypeScript and React Native. The catalog describes the rest: "the fundamentals of cross-platform mobile application development with a focus on the React Native framework", "developing best practices in creating apps for both iOS and Android", and what made React Native the primary mobile tool inside Facebook, Instagram, Airbnb, Walmart, Tesla and UberEats.
