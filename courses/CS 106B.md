# CS 106B: Programming Abstractions

The bridge out of the introductory course: C++ replaces Python, recursion and pointers replace loops and lists, and the weekly assignments — written in pairs this quarter — end in an interactive grading session with a section leader.

## Materials

The site is the course: slides, section handouts, assignments and policies are all public. Only the recordings are gated, which the syllabus states outright.

- **Syllabus**: [topics, attendance rules, exam dates and grade weights](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/course/syllabus). The separate [schedule page](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/schedule) builds its table in JavaScript, so its dates don't survive a plain fetch.
- **Slides**: a Google Slides deck on each lecture page — [lecture 1](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/lectures/01-welcome/) and lecture 2 so far — each exporting to PDF without an account.
- **Notes**: weekly [section handouts](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/sections/section1/) and standing guides: [Python to C++](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/course/python_to_cpp), [style](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/course/style_guide), [testing](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/course/testing_guide) and the [Stanford C++ library docs](https://web.stanford.edu/dept/cs_edu/resources/cslib_docs/).
- **Videos**: Canvas only.
- **Assignments**: [Assignment 0](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/assignments/0-namehash/) so far, roughly one a week after that.
- **Exams**: two proctored midterms (Oct 14, Nov 11) and a proctored final (Dec 7) that must be passed to pass the course; no public papers.
- **Projects**: none.
- **Code**: [blank Qt project](https://web.stanford.edu/dept/cs_edu/resources/qt/BlankProject.zip), a variant wired for the test suite, and per-assignment starter code.

## Syllabus

The [syllabus](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1272/course/syllabus) gives the topics in approximate order rather than by date:

1. C++ basics, coming from Python.
2. Abstract data structures.
3. Recursion.
4. Classes and object-oriented programming.
5. Memory management and implementation-level abstractions.
6. Linked data structures.
7. Advanced algorithms.

Grading is 25% assignments, 40% two midterms, 25% final, 10% lecture and section participation. Missing a lecture means watching the recording and passing a Gradescope quiz within 48 hours.

## Prerequisites

- Introductory programming: [CS 106A](CS%20106A.md), or a comparable course including high-school AP. No C++ needed — the course starts from Python.
