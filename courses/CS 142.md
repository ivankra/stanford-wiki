# CS 142: Web Applications

Stanford's long-running web course, taught by Mendel Rosenblum, and built on an argument the description makes explicitly: the web is now an application platform "displacing the traditional mechanism of installable binaries", which demands different approaches from desktop software.

## Materials

The whole course can be worked through from outside: schedule, every deck, every project brief with its starter code, and 28 solved exam papers sit on the open site. The one thing a visitor can't have is the lectures themselves, which are recorded to Canvas with no public copy.

- **Syllabus**: the [lecture schedule](https://web.stanford.edu/class/cs142/lectures.html), 10 weeks of MWF sessions dated April 3 to June 7, 2023, and the [class-info page](https://web.stanford.edu/class/cs142/info.html) with grading, late days, browsers, exams and regrades.
- **Slides**: an open [listing](https://web.stanford.edu/class/cs142/lectures/) of the 32 decks the schedule links, one or two a lecture, from [Intro](https://web.stanford.edu/class/cs142/lectures/Intro.pdf) and HTML through React and Express to session attacks, data centers and [future web app technology](https://web.stanford.edu/class/cs142/lectures/FutureWebAppTech.pdf).
- **Notes**: none beyond those decks, which the class-info page calls the lecture notes and which it sets against no reader and no required book: "The content of the course is defined by the lectures."
- **Videos**: recorded, but to Canvas, "under the Panopto Course Video Tab". No public set turned up under the code or the instructor's name.
- **Assignments**: the [8 project pages](https://web.stanford.edu/class/cs142/projects.html), building one photo-sharing application across the quarter: HTML and CSS, JavaScript calisthenics, the DOM, React page generation, a single-page app, an Express and MongoDB app server, sessions and input validation, then a sprint. They specify colors, pixel sizes and point splits down to the extra credit.
- **Solutions**: an answer PDF beside every sample paper but the Winter 2016 midterm, in the same [`downloads/`](https://web.stanford.edu/class/cs142/downloads/) listing; Spring 2016's final is answered by a set marked "Crowdsourced". Project solutions aren't published.
- **Exams**: 11 sample finals, 12 sample midterms and 5 online quizzes there too, Winter 2016 through Spring 2023.
- **Projects**: none; the 8 projects are graded coursework submitted on Gradescope, and no student work is shown.
- **Repo**: the starter-code zips projects 2 to 8 need are in `downloads/` beside an [install guide](https://web.stanford.edu/class/cs142/install.html) for Node.js and MongoDB, so the sequence runs on a laptop.
- **Older offerings**: the class archive keeps a complete site, decks and exam set for [Winter 2020](https://web.stanford.edu/class/archive/cs/cs142/cs142.1204/) and [Spring 2020](https://web.stanford.edu/class/archive/cs/cs142/cs142.1206/), [Winter 2021](https://web.stanford.edu/class/archive/cs/cs142/cs142.1214/) and [Spring 2021](https://web.stanford.edu/class/archive/cs/cs142/cs142.1216/), [Spring 2022](https://web.stanford.edu/class/archive/cs/cs142/cs142.1226/) and this offering. Winter 2022 and Winter 2023 have none.

## Syllabus

From the [lecture list](https://web.stanford.edu/class/cs142/lectures.html), ten weeks moving up the stack: markup and styling (HTML, CSS), addressing and protocols (URLs), the language (JavaScript basics, programming, newer features), the document model (DOM), then frameworks, server-side JavaScript, databases, and the security and deployment concerns that follow.

The catalog summarizes the span: "markup languages, scripting languages, network protocols, interactive graphics, event-driven programming, and databases, and see how they all work together to deliver exciting applications."
