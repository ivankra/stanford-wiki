# CS 142: Web Applications

Stanford's long-running web course, taught by Mendel Rosenblum, and built on an argument the description makes explicitly: the web is now an application platform "displacing the traditional mechanism of installable binaries", which demands different approaches from desktop software.

## Materials

Nearly everything is public, and the exam archive is unusually generous — six past finals, every one with solutions.

- **Syllabus**: the [lectures page](https://web.stanford.edu/class/cs142/lectures.html), grouped into ten weeks, plus a class-info page.
- **Slides**: [32 PDFs](https://web.stanford.edu/class/cs142/lectures/Intro.pdf) — Intro, HTML, CSS, URLs, three on JavaScript, the DOM, and onward through frameworks, server and database material.
- **Assignments** and **Projects**: the [project sequence](https://web.stanford.edu/class/cs142/projects.html), which builds one application across the quarter.
- **Exams**: [six sample finals](https://web.stanford.edu/class/cs142/downloads/SampleCS142FinalExam-Spring2022.pdf) — Spring 2016, Fall 2017, Spring 2018, Spring 2019 and Spring 2022.
- **Solutions**: [one per sample final](https://web.stanford.edu/class/cs142/downloads/SampleCS142FinalExam-Spring2022Solutions.pdf). The Spring 2016 set is labeled "Crowdsourced".
- **Notes**, **Videos**, **Code**: not found.

## Syllabus

From the [lecture list](https://web.stanford.edu/class/cs142/lectures.html), ten weeks moving up the stack: markup and styling (HTML, CSS), addressing and protocols (URLs), the language (JavaScript basics, programming, newer features), the document model (DOM), then frameworks, server-side JavaScript, databases, and the security and deployment concerns that follow.

The catalog summarizes the span: "markup languages, scripting languages, network protocols, interactive graphics, event-driven programming, and databases, and see how they all work together to deliver exciting applications."
