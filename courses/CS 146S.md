# CS 146S: The Modern Software Developer

The course treats coding agents as systems to be read rather than tools to be used: week 1 builds Claude Code in 200 lines and then dissects the system prompts of shipping agents. Half the sessions are guests from the companies making them — Cursor, Anthropic, Cognition, Factory, Semgrep, Replit. Open-source contributions are 30% of the grade, and fifteen projects are listed as partners to contribute to.

## Syllabus

From the site's [ten-week schedule](https://themodernsoftware.dev/), two sessions a week, the second usually a guest:

1. **Internals of coding agents** — what an LLM is and what the agent loop looks like underneath; the core tool set (read, write, edit, bash); how production agents structure system prompts and tool definitions.
2. **Advanced context engineering** — prompting techniques and when each applies; RePPIT (Research, Propose, Plan, Implement, Test) and spec-driven development; MCP servers, clients, tools and transport; designing tools for agent ergonomics.
3. **Agent skills and CLI** — how SKILL.md plus scripts encode a workflow; web skills; working from the CLI. Guest: Lee Robinson, Cursor.
4. **Customizing your agent and repository** — CLAUDE.md and AGENTS.md and what belongs in each; hooks for lint gates and test runs; planner/implementer/reviewer subagents. Guest: Boris Cherny, Anthropic.
5. **Agent-ready codebases** — structure, docs, tests and checks; scoring readiness; what blocks agents in real repos. Guest: Eno Reyes, Factory.
6. **Agentic code review** — what AI review catches and misses; review architectures and custom rules. Guest: Silas Alberti, Cognition.
7. **Security** — SAST/SCA, dependency and secret-leak vulnerabilities; prompt injection and agent-specific attack surfaces. Guest: Isaac Evans, Semgrep.
8. **Background agents** — async cloud-delegated agents, fleets of parallel agents, issue-to-PR pipelines. Guest: Rajesh Bhatia, Cloudflare.
9. **Building an AI-native team** — MCP portals, LLM gateways, model routing and cost. Guests: Elad Gil; Amjad Masad, Replit.
10. **The software factory** — self-running, self-improving systems; securing agents post-deployment.

Grading: final project 50%, open-source contributions 30%, weekly assignments 15%, participation 5%.
