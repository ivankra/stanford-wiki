# CS 107ACE: Problem-solving Lab for CS107

Two hours a week of [CS 107](CS%20107.md) in a small room: practice problems on the current topic, ACE-only office hours and exam review sessions. Undergraduates only, by application, graded on participation.

## Materials

Almost everything this section produces ends up readable, spread over three places: this quarter's class Drive, [Spring 2026](https://drive.google.com/drive/folders/1R9XOS4qdLeCBiQeNDh56cZYMT7ptssXM)'s, which holds that whole quarter, and the site from its CS 107A years, still up with the reference handouts and the assignment walkthroughs. The gap is this quarter's own decks: one is out, one folder is empty, and the site's own Slides link answers 401.
