# CS 242: Programming Languages

PL theory from small calculi upward, then applied to a survey of real languages. Seven weekly programming assignments, an in-class midterm and a cumulative final; all work is individual.

## Materials

The [course site](https://web.stanford.edu/class/cs242/) is public. Its [syllabus](https://web.stanford.edu/class/cs242/materials.html) links slides as lectures happen (1–2 so far), plus [Haskell notes](https://web.stanford.edu/class/cs242/materials/lectures/haskell-notes.pdf) and papers for readings. The [Autumn 2025 syllabus](https://web.stanford.edu/class/archive/cs/cs242/cs242.1262/materials.html) has slides for all 18 lectures on the same topic list. [Past exams](https://web.stanford.edu/class/cs242/exams.html) gives midterms and finals from Autumn 2021–2024, each with a solution. Recordings are on Canvas only; homework handouts aren't linked from any public page.

## Syllabus

Eighteen lectures:

1. **Foundations:** course overview; combinator calculus (two lectures); lambda calculus; typed lambda calculus; polymorphic types.
2. **Language features:** state, continuations, monads, objects. Midterm follows.
3. **Language survey:** Rust, Prolog, Haskell.
4. **Verification and types:** program verification via type theory, with CompCert and seL4 papers as reading; Agda; gradual typing.
5. **Array programming**, then wrap-up.

## Prerequisites

[CS 103](CS%20103.md) and [CS 110](CS%20110.md).
