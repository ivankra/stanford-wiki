# CS 110: Principles of Computer Systems

The undergraduate systems core for a decade, and now retired: [CS 111](CS%20111.md) replaced it from Spring 2022, splitting the old syllabus so that operating-systems concepts got their own course and the Pintos projects became [CS 112](CS%20112.md). Its last offering's site is still up and largely open.

## Materials

The last offering's site is still up and open: the dated schedule, a deck for every lecture, every assignment and lab with the labs' solutions, the code examples and a practice-exam library with answer keys. The recordings are the exception; the site's video link goes to Canvas and no public set exists.

- **Syllabus**: the [dated table](https://web.stanford.edu/class/cs110/) through lecture 25, with topic, materials, assignments and readings per session, and a [course-information document](https://cs110.quip.com/4bTOAuQXeFwk/Winter-2022-CS110-Course-Information) with the grading scheme.
- **Slides**: a [slides.com deck](https://slides.com/troccoli/cs110-win2122-lecture-1/fullscreen) for each of the 25 lectures; 3 sessions reuse Jerry Cain's Autumn 2021 decks.
- **Notes**: none on this site. The archived [Summer 2021 offering](https://web.stanford.edu/class/archive/cs/cs110/cs110.1218/summer-2021/) published lecture notes and concept checks alongside its decks, the only offering here that did.
- **Videos**: the Videos link is a Canvas external tool that lands on Stanford's login gateway, and the Stanford Online channel has no CS 110 playlist. A public [playlist of Spring 2019 lectures](https://www.youtube.com/playlist?list=PLu77E6J7s6Ko3Ft4XcOX1yKW6iX3eEFqS) exists but is a third party's upload from before the wiki's window, so it doesn't stand in for this offering.
- **Assignments**: [6 assignments and 9 weekly labs](https://cs110.quip.com/3qpTAmEkWcbO/Assignment-6-HTTP-Proxy-and-Cache) as Quip documents, from Six Degrees of Kevin Bacon to an HTTP proxy and cache with a proxy-chaining extension.
- **Solutions**: a [solution document](https://cs110.quip.com/wxcsAAN399T3/Lab-Solution-1-File-Systems-and-System-Calls) for every lab, and an answer key beside every practice exam. The assignments have none.
- **Exams**: [4 practice midterms and 3 practice finals](https://web.stanford.edu/class/cs110/assessments/practice/), each with its solution, plus the 2018-19 final's answer key. The three Winter 2022 papers themselves are not posted; the [Assessment Prep pages](https://web.stanford.edu/class/cs110/assessments/) say what each covered.
- **Projects**: none; the course has no term project.
- **Repo**: [per-lecture code examples](https://web.stanford.edu/class/cs110/examples/filesystems/) for filesystems, processes, threads and networking, served from the course host.
- **Textbook**: Saltzer and Kaashoek, *Principles of Computer System Design*.
- **Older offerings**: the class archive keeps all 7, Winter 2020 through Autumn 2021, each with its own schedule and handouts.

## Syllabus

The catalog states the scope: "Principles and practice of engineering of computer software and hardware systems. Topics include: techniques for controlling complexity; strong modularity using client-server design, virtual memory, and threads; networks; atomicity and coordination of parallel activities."

The [Winter 2022 schedule](https://web.stanford.edu/class/cs110/) runs 25 lectures to "MapReduce and Course Wrap-Up" on 7 March, with six assignments and a weekly lab. The textbook is Saltzer and Kaashoek, *Principles of Computer System Design*.
