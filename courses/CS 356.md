# CS 356: Topics in Computer and Network Security

A discussion seminar: each class covers 1–2 formative security papers, each student presents one recent paper, and small groups write an original research paper. In-person attendance is required, and there is no final exam.

## Materials

The [course site](https://cs356.stanford.edu/) is public and is the whole syllabus: the dated schedule links every required paper, and the reading-response, presentation and project requirements are spelled out. Submissions go through Gradescope and discussion through Ed. No slides, recordings or past projects are posted.

## Syllabus

1–2 papers per class, mostly formative work in each area:

1. Introduction: security nihilism, weak keys in network devices, how to read a paper
2. Web privacy and tracking; usability (browser warnings, AI coding assistants)
3. Authentication and phishing; spam and eCrime
4. System attacks and defenses (blind ROP, data-only attacks, WebAssembly, adaptive attacks on LLM defenses)
5. IoT botnets (Mirai); network security (Diffie-Hellman, satellite links)
6. Cyber-physical systems (cars, grid malware); hardware (Rowhammer, Spectre)
7. At-risk populations (intimate-partner spyware, state hacking); censorship
8. AI-enabled attacks and abuse (deepfake markets, Glaze); data leakage (de-anonymization, LLM training-data extraction)
9. Problem selection; final project presentations

## Prerequisites

None official. The catalog strongly encourages [CS 155](CS%20155.md) first; the site expects it or equivalent, plus a mature understanding of software systems and networks.
