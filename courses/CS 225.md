# CS 225: Machine Learning for Discrete Optimization

The premise is that a solver rarely faces a worst-case instance — it faces instances from one application, and there is usually data about them. So the course puts learned components inside combinatorial algorithms: pointer networks that produce TSP tours, GNNs that pick branching variables for integer programs, configuration procedures that tune a solver's parameters. Half of it is that applied machinery; the other half is the theory that says when a learned algorithm provably generalizes.

## Syllabus

[Six units](https://vitercik.github.io/ml4do/schedule/) from April 1.

1. Introduction (Apr 1).
2. Pointer networks for TSP (Apr 3-10): RNNs and sequence-to-sequence models, then Vinyals' pointer networks and Bello's REINFORCE-trained variant, against classical TSP approximation.
3. Graph neural networks (from Apr 15): graphs and graph algorithms, then GNN architectures.
4. Integer programming: where learned components enter the branch-and-bound pipeline.
5. Theoretical guarantees: what can be proved about a learned algorithm's performance.
6. Transformers, then final project presentations.
