# CS 193U: Video Game Development in C++ and Unreal Engine

Ran once, in Autumn 2020, on the engine behind Fortnite and Gears of War. 20 lectures build a single game, the ActionRoguelike project, which is still on GitHub. Taught by Tom Looman, an Unreal engineer who has since turned the same material into a commercial course — which is why the Stanford address now leads to a storefront and the coursework survives only in the Internet Archive.

## Materials

Everything the course handed students is still reachable — the syllabus, all 29 decks, the 7 weekly briefs and the reference project with the finished code in it — but only through the Internet Archive, because the page that indexed it was replaced by a sales funnel. The one thing held back is the lectures themselves, which were recorded and never released.

- **Syllabus**: the [archived page](http://web.archive.org/web/20210514120659/https://www.tomlooman.com/stanford-cs193u/) — prerequisites, setup for Windows and macOS, the lecture list, the weekly assignments, grading and the late policy.
- **Slides**: [29 Google Slides decks](https://docs.google.com/presentation/d/1IX6xUmi1RmUfZOHQOdCFylYVkxIeP2jrNjtqkTwbD1k/edit) across the 20 lectures. All 29 still export to PDF, 6 years after the only offering.
- **Notes**: per-lecture reading into Unreal's documentation, Epic's code standards and a community style guide.
- **Videos**: "The recorded classes are not yet publicly available". They were recorded; they have never been released.
- **Assignments**: 7 weekly briefs with their requirements written out in full — third-person movement and a magic projectile in week 1, blackhole and dash projectiles in week 2, health, damage and a potion in week 3.
- **Solutions**: the reference project carries the completed code, "added only after the deadline".
- **Exams**: none. **Projects**: the final-project brief is archived; no student game is published.
- **Repo**: [`tomlooman/ActionRoguelike`](https://github.com/tomlooman/ActionRoguelike), the project the course builds across its 20 lectures, public and still maintained.

## Syllabus

20 lectures building one game — the ActionRoguelike reference project — from the [archived lecture list](http://web.archive.org/web/20210514120659/https://www.tomlooman.com/stanford-cs193u/):

1. **Foundations** (1–5): course logistics, project start and version control, collision and physics, interfaces and collision queries, Blueprints.
2. **Systems** (6–9): debugging, UMG and player health, dynamic materials, audio and animation.
3. **AI** (10–13): behavior trees, BT tasks and EQS, GameMode.
4. **Architecture** (14–18): UMG with C++, CVARs, the Gameplay Ability System, GameplayTags, buffs and an interaction component.
5. **Multiplayer** (19–20): replication.

Assignments track the lectures: week 1 is third-person movement, a magic projectile and an explosive barrel re-implemented in C++; week 2 adds blackhole and dash projectiles; week 3 finishes health and damage and adds a health potion.

The catalog's own summary: "Hands-on game development in C++ using Unreal Engine 4, the game engine that triple-A games like Fortnite, PUBG, and Gears of War are all built on. Students will be introduced to the Unreal editor, game frameworks, physics, AI, multiplayer and networking, UI, and profiling and optimization. Project-based course where you build your own games and gain a solid foundation in Unreal's architecture that will apply to any future game projects. Pre-requisites: CS106B or CS106X required. CS107 and CS110 recommended."
