# CS 193C: Client-Side Internet Technologies

A summer-only course, and the oldest of Stanford's web-programming numbers still running: the browser stack on its own, without a server half. The catalog's reference points are Google Maps and Gmail — single-page applications built out of the DOM and Ajax.

## Syllabus

No published syllabus. The catalog lists the content: "Client-side technologies used to create web sites such as Google maps or Gmail. Includes HTML5, CSS, JavaScript, the Document Object Model (DOM), and Ajax."

The site records the format: two two-hour lectures a week, Tuesday and Thursday, in Gates B1.
