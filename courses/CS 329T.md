# CS 329T: Trustworthy Machine Learning: Building and evaluating agentic systems

Built on the premise that a prototype agent is easy and a reliable one is not: every architecture taught comes with the evaluation methods for it. Seventy percent of the grade is a team project carried through proposal, mid-term, dry-run and a poster fair, with one homework and no exam.

## Syllabus

Ten weeks ([schedule](https://web.stanford.edu/class/cs329t/syllabus)): foundation models, prompting and RAG; agentic AI foundations, sample architectures, and evaluation by goals, plans and actions; systematic evaluation, refining the LLM judge, and evaluation with and without ground truth; MCP and effective tool descriptions; a deep dive into LLMs; data curation and RL to optimize agents (SWE-bench, ARE, DAPO); GEPA and reflective prompt evolution; security for agents — adversarial attacks, circuit breakers, HarmBench; multi-modal frontier models. Weeks 3, 7–9 are project proposal, mid-term and semi-final presentations; week 10 is the project fair.
