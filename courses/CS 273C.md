# CS 273C: Cloud Computing for Biology and Healthcare

The infrastructure half of personalized medicine: storing and processing genome-scale biomedical data. Cloud and parallel systems architecture taught for people whose workloads are biomedical, by Genetics and CS faculty together.

## Syllabus

No syllabus is public. From the catalog description: big data is transforming healthcare, and real-time personalized healthcare needs hardware and software that can store and process large-scale biomedical datasets efficiently. The course teaches the concepts of cloud computing and parallel systems' architecture, so that students can design parallel programs for computationally intensive medical applications and run them on cloud computing and high performance computing (HPC) frameworks.

## Prerequisites

- Programming: familiarity with Python and R. Nothing else is stated, and no biology background is named.
