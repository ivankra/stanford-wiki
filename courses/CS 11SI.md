# CS 11SI: How to Make VR: Introduction to Virtual Reality Design and Development

Run by Stanford XR and capped at twenty students. The stated aim is reach rather than depth: "The course's objective is to democratize the knowledge of creating virtual reality, and the prerequisite is intentionally set to be very accessible to many students."

## Syllabus

From the [syllabus document](https://docs.google.com/document/d/1jwZBGwFY26bO7wAwgf38nr0PqsrAuqkyCH2V8YHYHIo/edit), the course's stated outcomes are to "Understand the Unity game engine and how to use it to create virtual reality applications", to "Gain knowledge on design best-practices for virtual reality and other immersive media", to "Work with a group to create an application for the Pico headset", and to "be able to speak confidently about virtual reality design and development."

Its shape: "Students learn how to creatively approach VR as a medium, and then learn to build VR by using the Unity game engine. By the end of the quarter, students will develop a real VR application while working in teams. The main focus will be on acquiring an understanding of the virtual reality medium and the technical pipeline to produce VR experiences."

## Prerequisites

- Programming at the level of [CS 106A](CS%20106A.md), and an application. Class size is limited to twenty; admitted students get a permission number and must attend the first class to confirm.
