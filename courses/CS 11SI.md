# CS 11SI: How to Make VR: Introduction to Virtual Reality Design and Development

Run by Stanford XR and capped at twenty students. The stated aim is reach rather than depth: "The course's objective is to democratize the knowledge of creating virtual reality, and the prerequisite is intentionally set to be very accessible to many students."

## Syllabus

From [Autumn 2023's syllabus](https://docs.google.com/document/d/1uSHRToMmxhXJmYPIpnXca_F2hz1fggMA_bXXpgwGBpM/edit), which runs in named phases. **Jumping In** (wk 1) opens with "What is Reality?". **The Unity Game Engine** (wk 2) is Unity Basics against the Roll-a-Ball tutorial. **VR Design Principles** (wk 3) sets up the XR Interaction Toolkit and its interaction model. **VR Development** (wk 4) playtests the students' Beatsaber clones and adds UI interaction. From **Project Brainstorming** (wk 5) the course turns into a studio: guest speakers from the VR industry, 3D modeling in Blender, collaboration tools, Unity animation and hand tracking, threaded between work days and the proposal, two milestones and Demo Day in week 10.

The goals, stated on every offering's doc: "Understand the Unity game engine and how to use it to create virtual reality applications", "Gain knowledge on design best-practices for virtual reality and other immersive media", "Work with a group to create an application for the [Oculus Quest / Pico] headset", and "be able to speak confidently about virtual reality design and development."

## Prerequisites

- Programming at the level of [CS 106A](CS%20106A.md), and an application. Class size is limited to twenty; admitted students get a permission number and must attend the first class to confirm.
