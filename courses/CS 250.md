# CS 250: Algebraic Error Correcting Codes

Coding theory taught algebraically and applied widely: the same Reed-Solomon machinery reappears as group testing, compressed sensing and distributed-storage repair. Run flipped — lectures are pre-recorded on YouTube, class time is group problem-solving — and graded entirely on three homeworks and a project, with no exam.

## Materials

Unusually complete for a theory course: the whole lecture series, the notes, the in-class problems *and* their solutions are public. Only homework solutions are held back.

- **Syllabus**: the [course site](https://web.stanford.edu/class/cs250/) is one page — structure, grading (28% project, 72% homework), late and LLM policies, and the class-by-class schedule.
- **Notes**: [lecture notes](https://web.stanford.edu/class/cs250/lectureNotes/Lecture1-compressed.pdf) for all sixteen content classes, one PDF each.
- **Videos**: the [YouTube playlist](https://youtube.com/playlist?list=PLkvhuSoxwjI_UudECvFYArvG0cLbFlzSr) of pre-recorded segments, three to five per class. In-class sessions aren't recorded.
- **Assignments**: [HW1](https://web.stanford.edu/class/cs250/Homework/HW1/hw1.pdf), [HW2](https://web.stanford.edu/class/cs250/Homework/HW2/hw2.pdf) and [HW3](https://web.stanford.edu/class/cs250/Homework/HW3/hw3.pdf), each with a LaTeX template, plus the [project guidelines](https://web.stanford.edu/class/cs250/Homework/finalproject.pdf).
- **Solutions**: [in-class problem solutions](https://web.stanford.edu/class/cs250/InClass/Class1_soln.pdf) for classes 1-15 are posted next to the problems; homework solutions go on Canvas.
- **Exams**: none — grading is homework and project only.
- Optional reading throughout is [Essential Coding Theory](https://cse.buffalo.edu/faculty/atri/courses/coding-theory/book/), the in-progress Rudra-Guruswami-Sudan book.

## Syllabus

[Eighteen classes](https://web.stanford.edu/class/cs250/), the last two given to project presentations.

1. Foundations (classes 1-4): definitions and the Hamming bound, finite fields and linear codes, McEliece, asymptotics, GV, Singleton and Plotkin bounds, Reed-Solomon codes.
2. Constructions and decoding (5-9): Welch-Berlekamp, BCH and Reed-Muller codes, concatenation and the Zyablov bound, compressed sensing and group testing, achieving capacity on the binary symmetric channel.
3. List decoding (10-13): capacity and the Johnson bound, Guruswami-Sudan, list-recovery, folded RS codes.
4. Locality (14-16): Reed-Muller and locality, local list-decoding via Goldreich-Levin and Kushilevitz-Mansour, RS codes as regenerating codes in distributed storage.

## Prerequisites

- Linear algebra.
- Basic probability: [CS 109](CS%20109.md), CME 106 or EE 178.
- "Mathematical maturity" — the homework is proofs. Finite fields help but aren't assumed; class 2 builds them up.
