# CS 146: Game Development

Deliberately the engineering counterpart to [CS 247G](CS%20247G.md): the catalog says it "complements CS247G: Design for Play by focusing on technical implementation." Students build in Unity or Unreal, wire up NPC behavior and procedural generation, and ship a team game with guest speakers from the industry.

## Materials

- **Exams**, **Code**: not found.

## Syllabus

No current syllabus. The catalog describes the content: "Game Programming teaches students the programming principles and workflows used in modern game development. Through hands-on projects in industry-standard game engines (Unity or Unreal), students implement core game mechanics, integrate AI techniques like NPC behavior and procedural content generation, and prototype interactive experiences… Students complete a team-based final game project and learn from guest speakers from the game industry."

The stale site adds the shape the course has had: modules, a calendar, an annual speaker series and an end-of-year showcase.
