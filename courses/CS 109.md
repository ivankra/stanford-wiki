# CS 109: Introduction to Probability for Computer Scientists

Probability taught for the uses computer scientists actually put it to: the first two thirds build the theory from counting up to inference, and the last third spends nine lectures on machine learning, from logistic regression to diffusion models.

## Materials

The schedule, the staff-written course reader and the lecture pages are public. The problem sets run inside a web app that needs an account, and the videos are on Canvas.

- **Syllabus**: the [schedule](https://web.stanford.edu/class/cs109/schedule.html) dates all 28 lectures, six problem sets and both exams; [policies](https://web.stanford.edu/class/cs109/handouts/syllabus.html) are separate.
- **Notes**: [Probability for Computer Science](https://probabilitycoders.stanford.edu/spr26), the course's own reader, plus a [Python for Probability](https://web.stanford.edu/class/cs109/handouts/python.html) handout, a LaTeX cheat sheet, and a [page per lecture](https://web.stanford.edu/class/cs109/lectures/1-Welcome/).
- **Videos**: Canvas.
- **Assignments**: six problem sets, taken in the [pset app](https://psetapp.stanford.edu/fall26/pset1/splash); the splash page loads, the sets need a login.
- **Exams**: midterm Thursday October 22 at 6:30pm, final Wednesday December 9; no papers published.
- **Projects**: none.

## Syllabus

The [schedule](https://web.stanford.edu/class/cs109/schedule.html) is grouped into five blocks:

1. **Core probability** (lectures 1–5): what probability is, conditional probability, Bayes' theorem, counting and combinatorics.
2. **Random variables** (6–9): expectation, moments, Poisson, continuous random variables, the normal distribution.
3. **Probabilistic models** (10–14): models, inference and general inference, multinomial and beta distributions — then the midterm.
4. **Uncertainty theory** (15–17): the central limit theorem, bootstrapping and p-values, algorithm analysis.
5. **Machine learning** (18–28): information theory, logistic regression, comparing classifiers, deep learning, diffusion, and three lectures of applications.

## Prerequisites

- Programming at [CS 106B](CS%20106B.md)'s level — the problem sets include Python code, and the site publishes a Python review handout for it.
- Multivariable calculus, MATH 51 or equivalent, for the continuous distributions.
