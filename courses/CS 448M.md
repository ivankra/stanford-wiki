# CS 448M: Making Making Machines for Makers

Not a course about fabricating objects but about fabricating the fabricators. Three machines are built, modified and hacked in sequence — an embroidery machine for custom textiles, a drag-knife paper cutter for ornamental design, and an XY plotter on an Arduino — each pushed from both ends: the mechanics, stepper motors, servos and electrical control on one side; the trajectory, tool-path and design algorithms on the other. It ends in a student-chosen project. The catalog's only non-technical requirement is a "desire to make things".

## Syllabus

From the catalog description; no public syllabus.

1. Systems and processes for making things with computer-aided design and manufacturing; an introduction to machines and machine tools.
2. Project 1: an embroidery machine for custom textiles.
3. Project 2: a paper-cutting machine with a drag knife, for ornamental design.
4. Project 3: an XY plotter with an Arduino controller.
5. Across all three: principles of operation — mechanical design, stepper motors and servos, electrical control, driving software — and the computer algorithms for trajectory, tool path and design.
6. A survey of current trends in interactive machines.
7. A final student-selected project.
