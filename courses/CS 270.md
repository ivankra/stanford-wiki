# CS 270: Modeling Biomedical Systems

The symbolic corner of biomedical informatics. Before software can diagnose, support a decision or screen a drug, the knowledge has to be written down in a form a machine can act on; this course is about how that is done and the tools the field uses to do it — Protégé, FHIR and the semantic web stack.

## Syllabus

No public syllabus for this offering. From the [catalog description](https://explorecourses.stanford.edu/search?view=xml-20200810&academicYear=20252026&q=CS&filter-departmentcode-CS=on&filter-coursestatus-Active=on), the course covers making biomedical information computable and machine-actionable so knowledge can be shared and reused across applications:

- Knowledge representation and data modeling
- Controlled terminologies
- Ontologies, authored hands-on in Protégé
- Interoperability, hands-on with FHIR, and semantic web technologies
- Symbolic AI

[Stanford Online's listing](https://online.stanford.edu/courses/bmds210-modeling-biomedical-systems) for the same offering adds knowledge graphs, reusable problem solvers and modeling problems in healthcare IT. Coursework has historically ended in a group project, which is what the public project reports are.
