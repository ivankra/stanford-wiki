# CS 44N: Great Ideas in Graphics

An introductory seminar for first-years: one graphics idea a fortnight — particles, collisions, subdivision, noise, ray marching — each reached through a short programming project in a browser sketching environment rather than through the rendering pipeline. Application required, enrollment small.

## Syllabus

No current schedule is public. The catalog describes "a hands-on interactive and fun exploration of great ideas from computer graphics… motivated by graphics concepts, mathematical foundations and computer algorithms", with an "eccentric selection" of ideas explored through short weekly programming projects and topics drawn partly from graphics history.

The Autumn 2020 site, the only published schedule found, ran: OpenProcessing and a JavaScript refresher; particle systems; collision detection with broad- and narrow-phase tests; geometric subdivision for curves and surfaces; shading languages on Shadertoy; procedural noise; and ray marching with implicit geometry as the final project. Whether the current offering follows the same order is not stated anywhere public.
