# CS 161: Design and Analysis of Algorithms

Offered all four quarters, and the summer offering is a different course from the others: eight weeks of three 1h45m lectures rather than ten weeks of shorter ones, with its own notes and problem sets.

## Materials

Nothing is public. The only page at the canonical URL is a Summer 2026 enrolment FAQ that names Canvas as the home for everything else.

- **Syllabus**: closed. The [public page](https://web.stanford.edu/class/cs161/) carries attendance policy and prerequisites but no schedule, reading list or grading breakdown; "The Canvas is where future updates will be posted."
- **Slides**, **Notes**, **Videos**, **Assignments**, **Exams**: closed, all on Canvas.
- **Projects**: none — the summer instructor states the class "will have no actual programming component (though in a few cases you may be expected to write short snippets of pseudocode)".

## Syllabus

No public syllabus exists, so the catalog text is the only source for content: worst and average case analysis; recurrences and asymptotics; efficient algorithms for sorting, searching and selection; binary search trees, heaps and hash tables; divide-and-conquer, dynamic programming, greedy algorithms, amortized analysis and randomization; and the fundamental graph problems — minimum-cost spanning tree, connected components, topological sort and shortest paths. Network flow and string searching are listed as possible additions.

The Summer 2026 instructor describes his offering as "based on complete different lecture notes, problem sets, etc." from the other quarters', with "a slightly heavier focus on analyzing algorithms… rather than designing them, and a heavier focus on algorithms for sorting and searching compared to graphs." Assessment there is two midterms and a final.

## Prerequisites

- Programming and data structures: [CS 106B](CS%20106B.md) or CS 106X. The FAQ asks for "what is a pointer, what is a while loop, be able to answer 'what does this code do'".
- Proofwriting and discrete mathematics: [CS 103](CS%20103.md) or CS 103B — "be able to write proofs about numbers that follow the 'proofwriting checklist'".
- Probability: [CS 109](CS%20109.md) or STATS 116, to the point of "manipulating probabilities and expected values".
