# CS 112: Operating systems kernel implementation project

The Pintos projects unbundled from the lectures. Students who already took [CS 111](CS%20111.md) write the kernel code without repeating the concepts, and the projects are 100% of the grade.

## Materials

There is no separate CS 112 site: the course shares every page with [CS 212](CS%20212.md), and all of it is public except recordings.

- **Syllabus**: the [shared schedule](https://www.scs.stanford.edu/26sp-cs212/sched/). It flags which sessions matter here — the four Friday sections on the Pintos projects, "highly recommended", and the concurrency and synchronization lectures, optional and not examined.
- **Slides**: [every lecture and section deck](https://www.scs.stanford.edu/26sp-cs212/notes/), with print versions and LaTeX sources.
- **Notes**: the [Pintos manual](https://www.scs.stanford.edu/26sp-cs212/pintos/pintos.html), also downloadable as one PDF.
- **Videos**: lecture recordings are not on the public site.
- **Assignments**: the [four project handouts](https://www.scs.stanford.edu/26sp-cs212/labs/project.html) with design-document templates, plus Lab 0 and a git setup guide.
- **Solutions**: exam solutions for most of the archive; none for the projects.
- **Exams**: the [archive](https://www.scs.stanford.edu/26sp-cs212/exams/) holds [CS 140](CS%20140.md) midterms and finals from 1999–2007. Nothing from this offering, and CS 112's own exams cover only Pintos.
- **Projects**: none beyond the four.
- **Code**: the [Pintos distribution](https://web.stanford.edu/class/cs212/pintos.tar.gz), also a git clone.

## Syllabus

The course is the four Pintos projects, in the order the [project handout](https://www.scs.stanford.edu/26sp-cs212/labs/project.html) sets:

1. **Threads** — the scheduler, alarm clock and priority donation.
2. **User programs** — argument passing, system calls and process management.
3. **Virtual memory** — paging, swapping and memory-mapped files.
4. **File systems** — extensible files, subdirectories and a buffer cache.

Each project is submitted with a design document. Teams may mix CS 112 and [CS 212](CS%20212.md) students; the projects are identical across the two.

## Prerequisites

- Operating systems concepts: [CS 111](CS%20111.md), or permission of the instructor. The staff are explicit that this is not negotiable — "If you take only one of CS111 and CS112, it should be CS111… it doesn't make sense to write kernel code without also learning OS concepts."

## Related

- [CS 111](CS%20111.md): the prerequisite, with lighter projects of its own.
- [CS 140E](CS%20140E.md): the alternative for more kernel hacking: a bare-metal OS for the Raspberry Pi, written from scratch, instead of Pintos on a simulator.
- [CS 212](CS%20212.md): the same projects plus the full lecture sequence in one quarter, for students who have not taken [CS 111](CS%20111.md). CS 112's Pintos work is 100% of its grade; in [CS 212](CS%20212.md) it is 50%.
