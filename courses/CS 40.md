# CS 40: Cloud Infrastructure and Scalable Application Deployment

Stanford's first hands-on introductory cloud course, written and taught by students with a faculty sponsor. The premise is practical to the point of paying for itself: "There is no out-of-pocket cost associated with this class and cloud credits will be provided for all students."

## Materials

Winter 2024's offering is public end to end — the schedule, all 16 decks, every assignment and an entire GitHub organization of starter code and autograders — and that is what a reader gets. Autumn 2024 added nothing to it: the site still reads Winter 2024, and that offering's syllabus went to Canvas for Stanford accounts only.

- **Syllabus**: the [dated schedule](https://infracourse.cloud/), 16 lectures in 8 units with the assignment deadlines marked, plus a [course-info page](https://infracourse.cloud/info/) — all Winter 2024's. Autumn 2024's is a Canvas upload readable by Stanford accounts.
- **Slides**: [16 lecture PDFs](https://infracourse.cloud/lectures/2024-01-08-intro.pdf), one per session, named by date, and kept in the site's own repository as well.
- **Notes**: none found; the decks are the instruction.
- **Videos**: the schedule marks exactly one session as recorded, the evening primer on web-app basics, and that recording is on Ed. The 16 lectures themselves were not recorded.
- **Assignments**: [4 assignment pages](https://infracourse.cloud/assignments/1/) and a [final-project brief](https://infracourse.cloud/assignments/project/), with the starter code and autograders they need in the GitHub organization.
- **Solutions**: not published. **Exams**: none; the grade is the assignments and the project.
- **Projects**: the brief is public, no student work is.
- **Repo**: the [`infracourse` organization](https://github.com/infracourse), 11 public repositories — `simple-static` for assignment 1, `assignment2` starter code, 4 autograders including `iac-grader`, the `yoctogram-web` sample app, lecture `demos`, an AWS `provisioner`, and the Hugo source of the site. Everything in it was last pushed in March 2024.

## Syllabus

Eight units across the quarter, from the [schedule](https://infracourse.cloud/):

1. **Foundations of cloud computing** — building blocks of cloud infrastructure, a networking crash course, and an evening primer on how web apps work.
2. **Cloud networking and data flows** — cloud networking in practice.
3. **Databases and data management.**
4. **Programmatically managing infrastructure at scale** — containerization and orchestration, then infrastructure-as-code and cloud automation tools.
5. **Security and observability** — identity and access management, auditing and logging, two cloud-security sessions.
6. **Managed computing and cloud machine learning** — serverless computing, machine learning and HPC.
7. **Managing large-scale cloud deployments** — CI/CD, a fireside chat, practical considerations, ethical considerations, and cloud billing.
8. **Emerging trends** — the evolution of the cloud ecosystem, and a closing "Everything We Forgot To Tell You".

## Prerequisites

- Programming maturity to [CS 107](CS%20107.md).
- Tooling at the level of [CS 45](CS%2045.md) or [CS 104](CS%20104.md): "Basic Unix command line utilities and administration; Editing code with a TUI editor such as vim, emacs, or nano; Using Git and GitHub for collaborative projects; Basic familiarity with package managers". Prior web or networking experience is "helpful but not required".
