# CS 40: Cloud Infrastructure and Scalable Application Deployment

Stanford's first hands-on introductory cloud course, written and taught by students with a faculty sponsor. The premise is practical to the point of paying for itself: "There is no out-of-pocket cost associated with this class and cloud credits will be provided for all students."

## Materials

Everything from the Winter 2024 offering is public — the schedule, all sixteen decks, the assignments, and an entire GitHub organization of starter code and autograders.

- **Syllabus**: the [dated schedule](https://infracourse.cloud/), sixteen lectures in eight units, plus a course-info page.
- **Slides**: [sixteen PDFs](https://infracourse.cloud/lectures/2024-01-08-intro.pdf), one per session.
- **Videos**: closed — the only recording mentioned, an evening primer on web-app basics, is on Ed.
- **Assignments**: [four assignment pages](https://infracourse.cloud/assignments/1/) and a final project.
- **Code**: the [`infracourse` organization](https://github.com/infracourse) — `simple-static` for assignment 1, `assignment2` starter code, four autograders, `iac-grader`, lecture `demos`, an AWS `provisioner`, and the Hugo source of the site itself.
- **Notes**, **Solutions**: not found. **Exams**: none.

## Syllabus

Eight units across the quarter, from the [schedule](https://infracourse.cloud/):

1. **Foundations of cloud computing** — building blocks of cloud infrastructure, a networking crash course, and an evening primer on how web apps work.
2. **Cloud networking and data flows** — cloud networking in practice.
3. **Databases and data management.**
4. **Programmatically managing infrastructure at scale** — containerization and orchestration, then infrastructure-as-code and cloud automation tools.
5. **Security and observability** — identity and access management, auditing and logging, two cloud-security sessions.
6. **Managed computing and cloud machine learning** — serverless computing, machine learning and HPC.
7. **Managing large-scale cloud deployments** — CI/CD, a fireside chat, practical considerations, ethical considerations, and cloud billing.
8. **Emerging trends** — the evolution of the cloud ecosystem, and a closing "Everything We Forgot To Tell You".

## Prerequisites

- Programming maturity to [CS 107](CS%20107.md).
- Tooling at the level of [CS 45](CS%2045.md) or [CS 104](CS%20104.md): "Basic Unix command line utilities and administration; Editing code with a TUI editor such as vim, emacs, or nano; Using Git and GitHub for collaborative projects; Basic familiarity with package managers". Prior web or networking experience is "helpful but not required".
