# CS 42SI: From Player to Maker: 2D Engine-Based Game Development

Twenty students, two units, and several finished games each: the course runs the game-development lifecycle repeatedly in Unity, alone and in teams, and ends by publishing the results into a public game jam that anyone can play.

## Materials

The syllabus and the finished student games are public; the coursework itself is on Canvas.

- **Syllabus**: the [Google Doc](https://docs.google.com/document/d/1PsrNgMwiYHUNRDHz7Ueq-maVvIi6Eu5X6uMMY35iYAw/edit) the course calls its main source of information, marked tentative.
- **Assignments**: weekly deliverables go through Canvas, "only visible to enrolled/auditing students".
- **Projects**: the [gallery](https://cs42si.stanford.edu/) links previous students' games on itch.io, submitted to Tree Jam 2025.
- **Videos**, **Code**: none published; teams use GitHub privately.
- **Exams**: none.

## Syllabus

The published syllabus gives objectives rather than weeks: understand the Unity engine well enough to build with it, run the game-development lifecycle several times individually and in groups, and finish with "functional video game prototypes displayable on a portfolio". Ideation tools borrowed from the Design program open each project; C# is the language throughout; GitHub carries the team work; and the quarter's end is a game jam with the games published on live sites.

Class time is activities, discussion and group work, so attendance and weekly deliverables are both expected.

## Prerequisites

- Programming at [CS 106A](CS%20106A.md)'s level or AP Computer Science, since Unity scripting is in C#. Enrollment is capped at 20 and by application only.
