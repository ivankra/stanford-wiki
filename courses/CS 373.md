# CS 373: Statistical and Machine Learning Methods for Genomics

Tang and Kundaje teach the statistical machinery of genomics against the tools that actually implement it: each method is illustrated by an existing package used in population genetics, disease association or regulatory genomics, and the homework asks students to implement some of the algorithms themselves and to run the toolkits on real genomic datasets. Lectures alternate with discussion of primary-literature readings.

## Syllabus

From the catalog description; no public syllabus.

1. Statistical and computational foundations: expectation maximization; hidden Markov models; Markov chain Monte Carlo.
2. Modern machine learning paradigms: ensemble learning, probabilistic graphical models, kernel methods.
3. Rationales and techniques illustrated with existing implementations used in population genetics, disease association studies and functional regulatory genomics.
4. Lectures plus discussion of readings from the primary literature.
5. Homework and projects requiring students to implement some of the algorithms and to use existing toolkits on genomic datasets.
