# CS 146J: Full-Stack Web Programming

A practice-first web course, explicit about being for people who want to build the thing rather than use a site builder. It expects students to pick up unfamiliar languages quickly, and ends with a team app of the students' own design.

## Syllabus

No published syllabus. The catalog gives the arc: "we'll cover the fundamentals of full-stack web development, from how to create a stunning frontend (the website your users see and interact with) and a robust backend (the server that forms the backbone of your website), with a focus on modern technologies that are widely used across the industry, from startups to large tech companies. While this course focuses primarily on the practice of programming web applications, we will also cover the conceptual aspects of how web technologies work. At the end, you'll work in a team to build a large web app of your own design from scratch!"
