# CS 106AX: Programming Methodologies in JavaScript and Python (Accelerated)

[CS 106A](CS%20106A.md)'s accelerated twin, scheduled at the same hour so students can switch between them in the first week. Prior experience buys a faster pass over the basics, two languages instead of one, and larger assignments.

## Materials

Slides, code and TA notes go up lecture by lecture and are public; nothing that has been published is gated.

- **Syllabus**: the [course-information sheet](https://web.stanford.edu/class/cs106ax/res/handouts/01-General-Information.pdf) and a [calendar handout](https://web.stanford.edu/class/cs106ax/res/handouts/02-Calendar.pdf); grade weights are on the [landing page](https://cs106ax.stanford.edu/).
- **Slides**: each lecture on the [lectures page](https://web.stanford.edu/class/cs106ax/lectures.html) carries a PDF and a PPTX.
- **Notes**: separate [TA-written notes](https://web.stanford.edu/class/cs106ax/res/ben-notes/cs106ax-lecture01-notes.pdf) per lecture, plus a [JavaScript reader](https://web.stanford.edu/class/cs106ax/res/extras/CS106AX-JavaScript.pdf).
- **Videos**: none linked.
- **Assignments**: the [assignments directory](https://web.stanford.edu/class/cs106ax/assignments/) is unlinked but open. This offering's `assign-1.zip` went up on 27 September, and an `older/` subdirectory carries the previous offering's full set, `assign-2` through `assign-8`, with separate milestone and demo bundles for assignments 4, 6 and 7 — files dated October 2024 to November 2025. They carry half the grade.
- **Exams**: a midterm (15%) and a final (25%); no public papers.
- **Projects**: none.
- **Code**: a zip of the day's examples with every lecture.

## Syllabus

The course teaches two languages and the boundary between them: JavaScript for interactivity inside the browser, Python for the server that synthesizes and delivers the pages. Around them sit the same engineering themes as [CS 106A](CS%20106A.md), taken further — object-oriented design, decomposition, encapsulation, abstraction and testing — with graphics assignments built on the course's JSGraphics library.

Grading: 50% programming assignments, 15% midterm, 25% final, 10% attendance and participation.

## Prerequisites

- Some prior programming experience, in any language. The catalog and the site both frame this as the difference from [CS 106A](CS%20106A.md), which assumes none.
