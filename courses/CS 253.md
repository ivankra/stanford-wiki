# CS 253: Web Security

Taught by a practitioner rather than a researcher — Aboukhadijeh runs a supply-chain security company and took the course through Stanford himself — which shows in the shape: the most common attacks and their countermeasures, worked as five assignments against real browser behavior rather than as a literature survey.

## Syllabus

Twenty sessions in four parts, per the [schedule](https://web.stanford.edu/class/cs253/):

1. **Basics**: what web security is, DNS and HTTP, the same-origin policy.
2. **Client-side attacks and defenses**: cookies and sessions, session attacks and CSRF, cross-site scripting and its defenses (CSP, Trusted Types), denial of service and phishing, online tracking.
3. **Server-side attacks and defenses**: code and SQL injection, server security and safe coding, HTTPS and the lock icon (guest lecture by Dan Boneh), HTTPS in the real world (Chrome's Joe DeBlasio), authentication, WebAuthn (GitHub's Lucas Garron).
4. **Web security in the real world**: local HTTP server security, real-world browser security (Brave's Yan Zhu), DNS rebinding, browser architecture and writing secure code.

Grading: five assignments at 15% each, and a final worth 25%; there is no midterm.
