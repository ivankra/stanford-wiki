# CS 253: Web Security

Taught by a practitioner rather than a researcher — Aboukhadijeh runs a supply-chain security company and took the course through Stanford himself — which shows in the shape: the most common attacks and their countermeasures, worked as 5 assignments against real browser behavior rather than as a literature survey.

## Materials

Everything is public and nothing asks for an account: the schedule, all 19 decks, all 5 assignments, and three past finals with worked solutions — a combination almost nothing else in this wiki publishes. Recordings are the one thing this offering does not link, and the instructor's own channel carries the same 19 lectures from 2 years earlier.

## Syllabus

20 sessions in 4 parts, per the [schedule](https://web.stanford.edu/class/cs253/):

1. **Basics**: what web security is, DNS and HTTP, the same-origin policy.
2. **Client-side attacks and defenses**: cookies and sessions, session attacks and CSRF, cross-site scripting and its defenses (CSP, Trusted Types), denial of service and phishing, online tracking.
3. **Server-side attacks and defenses**: code and SQL injection, server security and safe coding, HTTPS and the lock icon (guest lecture by Dan Boneh), HTTPS in the real world (Chrome's Joe DeBlasio), authentication, WebAuthn (GitHub's Lucas Garron).
4. **Web security in the real world**: local HTTP server security, real-world browser security (Brave's Yan Zhu), DNS rebinding, browser architecture and writing secure code.

Grading: 5 assignments at 15% each, and a final worth 25%; there is no midterm.
