# CS 253: Web Security

Taught by a practitioner rather than a researcher — Aboukhadijeh runs a supply-chain security company and took the course through Stanford himself — which shows in the shape: the most common attacks and their countermeasures, worked as five assignments against real browser behavior rather than as a literature survey.

## Materials

Open, including past exams — one of the few courses in this wiki publishing both assignments and finals.

- **Syllabus**: the [site](https://web.stanford.edu/class/cs253/) is one page with the description, staff and everything else linked from it.
- **Assignments**: all five, [assign0 through assign4](https://web.stanford.edu/class/cs253/assign1), each its own page.
- **Exams**: past finals as PDFs, including [2021](https://web.stanford.edu/class/cs253/cs253-final-2021.pdf) and 2019.
- **Solutions**: partial — some archived finals come with [worked solutions](https://web.stanford.edu/class/cs253/cs253-final-2019-solutions.pdf), not all.
- **Slides and videos**: neither is linked.

## Syllabus

No dated schedule is published. The site states the scope: "a comprehensive overview of web security … the most common web attacks and their countermeasures … the fundamentals as well as the state-of-the-art", with the browser security model as the organizing idea.
