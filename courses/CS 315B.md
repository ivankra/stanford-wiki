# CS 315B: Parallel Computing Research Project

Aiken's argument is that bulk-synchronous programming has run out of road as machines grow, and that tasking is the leading alternative — so the course teaches the Legion runtime through two front ends: Regent, a tasking language, and cuNumeric, which presents itself as NumPy but runs on a cluster. It is deliberately open to computational scientists as well as computer scientists, and assumes little background beyond real programming ability. Six short exercises, no exams, and a supercomputer application of the student's own choosing.

## Materials

Every lecture deck is public, and the course says in its first line that nothing else will be: the 6 exercises and the project all go through Canvas, and no offering is archived.

## Syllabus

[The schedule](https://web.stanford.edu/class/cs315b/) works from the status quo to the alternative.

1. Foundations (9/27-9/29): course introduction, supercomputer architectures, bulk synchronous and SPMD programming.
2. Tasking (10/11-10/27): introduction to tasking and Regent, regions and how data is partitioned, metaprogramming, I/O and control replication.
3. Projects and comparison (11/3-11/17): project proposal meetings, then system comparisons across the programming models surveyed.
