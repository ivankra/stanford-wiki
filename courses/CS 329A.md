# CS 329A: Self Improving AI Agents

A paper-driven seminar on agents that get better by acting: verification, search and RL at both test and train time, with six guest lectures from DeepMind, Physical Intelligence, Reflection AI and LMCache, three homeworks and a team research project graded at 35%.

## Syllabus

Twenty sessions ([schedule](https://cs329a.stanford.edu/#schedule)), roughly one theme per lecture: test-time compute scaling (repeated sampling, Archon); robust verification (weak verifiers, process reward models); learning from feedback with tools and code (ReAct, RLEF, constitutional AI); multi-step reasoning and planning (SWiRL, tree search, ADaPT); train-time scaling with RL (STaR, GRPO, DAPO); open-ended evolution of self-improving agents (ADAS, AI Scientist, AlphaEvolve); search and deep-research agents; agentic frameworks for software engineering (CodeMonkeys, KernelBench); memory (Cartridges, MemGPT); and agentic evaluation over long-horizon tasks (GDPval, DeepScholar-Bench). Three lecture slots go to mid-term project presentations, six to guest lectures.
