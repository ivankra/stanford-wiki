# CS 140E: Operating systems design and implementation

No lectures and no simulator. Two labs a week, starting at 5:30pm "and going til you feel like leaving", building a working OS for the Raspberry Pi out of the Broadcom and ARMv6 manuals — "learning to understand such prose is one of the super-powers of good systems hackers."

## Syllabus

From the [labs README](https://github.com/dddrrreee/cs140e-26win/blob/main/labs/README.md):

1. **Non-pi hacking** (labs 0–1): an intro lecture with machine-code examples "showing how observability interacts with compiler optimization", then a reimplementation of Ken Thompson's trusting-trust attack — "a crazy hack he described in his Turing award lecture that let him log into any Unix system in a way hidden even from careful code inspection." These two need no hardware, deliberately: "They should give a good feel for whether the class works for you without requiring a hardware investment."
2. **Going down to metal**: the low-level code to run the Pi, validated with modern techniques, removing the magic from the boot path.
3. **The OS proper**: interrupts, threads, virtual memory and a simple FAT32 file system, ending in a final project.

[CS 240LX](CS%20240LX.md) labs, going back to 2020, may be taken as hard extensions.

## Prerequisites

None stated beyond an application. The catalog is explicit: "All hardware is supplied by the instructor, and no previous experience with operating systems, raspberry pi, or embedded programming is required."
