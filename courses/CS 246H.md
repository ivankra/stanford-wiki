# CS 246H: Mining Massive Data Sets Hadoop Lab

A 1-unit, credit/no-credit supplement to [CS 246](CS%20246.md): the same algorithms, implemented against the Apache stack as it stood around 2020 — Hadoop and Spark for computation, Hive and Impala for SQL, Kafka, Sqoop and Flume for ingest, Avro and Parquet on disk. It exists because the main course teaches the algorithms and leaves the plumbing out.

## Materials

Winter 2020 published nothing: the site was never rolled over, no syllabus went to Canvas, and the class path now 404s. What a reader can still get is the Internet Archive's copy of the Winter 2019 site, captured inside Winter 2020 while it was still live — the schedule and all 7 homework bundles, data included. The 10 decks that went with them were captured as redirects and do not resolve, so the instruction is missing while the practice survives.

- **Syllabus**: none for this offering. The [archived Winter 2019 site](https://web.archive.org/web/20200212164650/http://web.stanford.edu/class/cs246h/) gives the framing — "adapted from the professional courses taught by Cloudera", "on the practical application of big data technologies, rather than on the theory behind them" — the staff, the Wednesday meeting, and a [handouts page](https://web.archive.org/web/20200212164650/http://web.stanford.edu/class/cs246h/handouts.html) dating all 10 lectures from Introduction to Hadoop through Spark internals, parallelism, DataFrames, streaming, SparkML, Hive and Impala, to Sqoop, Avro and Parquet.
- **Slides**: the handouts page links a deck for each of those 10 lectures under `slides19/`. Every one was captured as a redirect rather than a file, so none opens, in the archive or anywhere else.
- **Notes**, **Solutions**, **Repo**: nothing found. The starter code ships inside the lab zips rather than in a repository.
- **Videos**: nothing for this offering. The Winter 2018 [CS 246](CS%20246.md) site linked a lecture-video page for the lab on Stanford's MVideoX platform, which has since been retired.
- **Assignments**: [7 homeworks](https://web.archive.org/web/20200212164650/http://web.stanford.edu/class/cs246h/hw/tutorial.pdf) all download from the archive — a 4.5 MB tutorial as Homework 0, 5 lab bundles as zips (combiner, partitioner, counters, writables, sequence file), 3 of them 54 MB because the datasets ship inside, and a streaming homework as a PDF. `electric.csv` and `major_cities.tsv` are archived beside them.
- **Exams**: an archived announcements block lists 7 weekly quizzes plus a bonus, posted to an `info.html` page. None is published.
- **Projects**: none; a 1-unit lab whose work is the bundles.

## Syllabus

From the catalog description; no public syllabus.

1. Implementing data mining algorithms using Hadoop and Apache Spark.
2. Implementing and debugging complex data mining jobs and data transformations.
3. Two of the popular big-data SQL tools: Apache Impala and Apache Hive.
4. Data ingest and interchange: Apache Kafka, Apache Sqoop, Apache Flume, Apache Avro, Apache Parquet.

## Prerequisites
