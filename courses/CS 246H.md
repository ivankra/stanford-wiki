# CS 246H: Mining Massive Data Sets Hadoop Lab

A one-unit, credit/no-credit supplement to [CS 246](CS%20246.md): the same algorithms, implemented against the Apache stack as it stood around 2020 — Hadoop and Spark for computation, Hive and Impala for SQL, Kafka, Sqoop and Flume for ingest, Avro and Parquet on disk. It exists because the main course teaches the algorithms and leaves the plumbing out.

## Materials

The site is gone from the live server, but the Internet Archive has it whole.

- **Syllabus**: no site under `cs246h` at any of the usual paths, and the current [CS 246](CS%20246.md) site does not link or mention the lab.
- No handouts, datasets or starter code are served today.
- **Extra**: the archive holds [the Winter 2019 site](https://web.archive.org/web/20200212164650/http://web.stanford.edu/class/cs246h/) — its home, handouts and course-info pages, four homework PDFs, six lab bundles as zips (two of them 54 MB, so the data ships with them), a 4 MB tutorial PDF and the `electric.csv` and `major_cities.tsv` datasets. Seven years old, so no rating; the site's own framing is that the course "is adapted from the professional courses taught by Cloudera" and is "on the practical application of big data technologies, rather than on the theory behind them".

## Syllabus

From the catalog description; no public syllabus.

1. Implementing data mining algorithms using Hadoop and Apache Spark.
2. Implementing and debugging complex data mining jobs and data transformations.
3. Two of the popular big-data SQL tools: Apache Impala and Apache Hive.
4. Data ingest and interchange: Apache Kafka, Apache Sqoop, Apache Flume, Apache Avro, Apache Parquet.

## Prerequisites
