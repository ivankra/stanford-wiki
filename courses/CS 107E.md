# CS 107E: Computer Systems from the Ground Up

The seven assignments are one program: each week's work becomes the next week's foundation, ending in a bare-metal console — keyboard, shell, graphics, interrupts — running on a Mango Pi MQ-Pro with no operating system under it.

## Materials

The teaching site is fully public — schedule, labs, all seven assignments, the guides and a project gallery — and the starter code the assignments need is still in the public git history of the site itself. The course makes no recordings at all, so there is nothing withheld there.

- **Syllabus**: the [week-by-week schedule](https://cs107e.github.io/schedule/), with readings keyed to Kernighan and Ritchie and to Nick Parlante's *EssentialC*.
- **Slides**: none posted, and the site never says whether the lectures use any.
- **Notes**: the [guides](https://cs107e.github.io/guides/), a RISC-V cheatsheet, the D1-H peripheral manual and a Mango Pi pinout card.
- **Videos**: none by policy — "Lectures are not recorded and lecture attendance is expected."
- **Assignments**: [all seven plus the final project](https://cs107e.github.io/assignments/), with the staff's own workload estimate of 10–20 hours each and over 20 for the project.
- **Solutions**: none posted. Work is marked on the pull request a student submits, and nothing says a key exists.
- **Exams**: none. "There are no exams in CS107E."
- **Projects**: a [gallery of past final projects](https://cs107e.github.io/project_gallery/), with external demos beside it.
- **Repo**: the [lab exercises](https://cs107e.github.io/labs/) are public; assignment git repositories go to enrolled students, who submit by pull request. The assignment files are still public in the site repository's history, from before an ["unrelease" commit](https://github.com/cs107e/cs107e.github.io/commit/5494f2e2be7f2279350ddfe5bb0e7f974e52b432) removed them.
- **Textbook**: Kernighan and Ritchie's *The C Programming Language*, reached through Stanford's Safari subscription, and Parlante's *EssentialC*, which is free.

## Syllabus

From the [posted schedule](https://cs107e.github.io/schedule/), two Monday/Friday lectures and one lab a week:

1. **Weeks 1–2**: intro to RISC-V, assembly and machine code, from assembly to C, pointers and arrays. Lab 0 orientation, Lab 1 the Mango Pi; Assignment 0 git, Assignment 1 Larson scanner.
2. **Weeks 3–4**: C functions, the serial protocol, modules and linking, memory management. Assignment 2 a clock, Assignment 3 string formatting.
3. **Weeks 5–6**: C mastery, keyboards and the PS/2 protocol, sensor input. Assignment 4 stack and heap, Assignment 5 keyboard and a simple shell.
4. **Weeks 7–8**: graphics and interrupts. Assignment 6 a graphics library and console, Assignment 7 a system monitor with interrupts.
5. **Final weeks**: an open-ended team project implementing a complete hardware/software system, demoed on the last day of finals week.

## Prerequisites

- Programming and data structures: [CS 106B](CS%20106B.md) or CS 106X, and nothing further — "our one strict filter is to confirm the essential prereq".
- Consent of instructor: enrollment is capped at 40 and settled by questionnaire before the quarter, with priority to freshmen and sophomores.

A $75 lab fee covers the parts kit: the SBC, cables, breadboard, jumpers, LEDs and transistors. The SBC is now collected at course end rather than kept.
