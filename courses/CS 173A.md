# CS 173A: Foundations of Computational Human Genomics

A coder's primer to computational biology, using the human genome as "source code": genes as variables, regulation as control flow, repeats as memory leaks, disease as bugs. It includes primers on molecular biology and text processing.

## Materials

The course has never had a public site under any of its 4 codes, and its syllabus goes to Canvas readable inside Stanford alone. The one thing an outside reader can open is an unlinked directory of 2 problem sets from Winter 2023.

- **Syllabus**: Canvas, Stanford-only, for Autumn 2024, Autumn 2025 and this offering; the repository shows no upload at all for the earlier ones.

## Syllabus

From the catalog description (no public syllabus):

- Genome "code development": positive, negative and neutral selection
- Genome sequencing: reassembling the code from fragments
- Genome content: genes, gene regulation, epigenomics, repeats
- Personalized genomics and genetic disease
- Genome editing
- Ultra-conservation, and genome changes behind animal adaptations
- Primers on molecular biology and text processing
