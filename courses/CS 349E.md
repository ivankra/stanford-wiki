# CS 349E: Efficient ML Inference at Scale

How to serve large models with low latency, high throughput and low cost on heterogeneous machines, from model optimization down to kernels and compilers. Four weekly assignments in the first half, then a project. Compute is provided by Gimlet Labs.

## Syllabus

Nineteen lectures, twice weekly:

1. Introduction; transformers
2. Accuracy, quantization and sparsity; optimizing autoregressive decode (Orca, speculative decoding)
3. Disaggregated serving; distributed serving
4. Modeling hardware performance; hardware engines
5. Project pitches; KV cache management (PagedAttention, Mooncake)
6. Kernel development (FlashAttention, megakernels); kernel optimization techniques
7. Guest lecture
8. ML compilers: frontends; kernel generation
9. Agentic kernel generation (KernelBench, AlphaEvolve); agentic tool use
10. Project presentations
