# CS 110L: Safety in Systems Programming

Two units taken beside [CS 110](CS%20110.md), and effectively Stanford's Rust course: the catalog frames it as program analysis and robust systems software, and the lectures work through ownership, error handling and concurrency in Rust.

## Materials

The site is small and entirely open, and its directories are indexed, so there is more on it than the schedule links: two offerings' worth of decks, seven handouts, every exercise set and both project briefs. The starter code the exercises need went out through GitHub Classroom, but the instructor's own repository of it is public.

- **Syllabus**: the [schedule page](https://web.stanford.edu/class/cs110l/pages/schedule/), the dated lecture list on the landing page, and a [course-information handout](https://web.stanford.edu/class/cs110l/handouts/course-information/).
- **Slides**: [33 lecture PDFs](https://web.stanford.edu/class/cs110l/slides/) in one open directory — 14 for this offering, named with a `-2022` suffix, plus a guest lecture, and 18 unsuffixed ones from the Spring 2021 offering.
- **Notes**: [7 handouts](https://web.stanford.edu/class/cs110l/handouts/) — course information and material, git tips, Linux setup, a style guide, tools tips and a vim cheat sheet.
- **Videos**: not found. No source says the twice-weekly sessions are recorded.
- **Assignments**: [5 weekly exercise sets](https://web.stanford.edu/class/cs110l/assignments/) covering weeks 1, 2, 3, 5 and 7, and 2 project briefs, the second [dated to this offering](https://web.stanford.edu/class/cs110l/assignments/project-2-2022/) and built around a load balancer.
- **Solutions**: not found.
- **Exams**, **Projects**: none. The two "projects" are graded assignments, and no student work is published.
- **Repo**: only [week 1's starter archive](https://web.stanford.edu/class/cs110l/assignments/week-1-exercises/week1.zip) is served from the site; the other weeks went through GitHub Classroom. The instructor keeps the [Spring 2020 starter code](https://github.com/reberhardt7/cs110l-spr-2020-starter-code) public, with weeks 1, 2, 3, 5 and 6 and both projects, which is the only public route to the scaffolding.

## Syllabus

The catalog states the aim: "Explores how program analysis tools can find common bugs in programs and demonstrates how we can use the Rust programming language to build robust systems software. Course is project-based and will examine additional topics in concurrency and networking through the lens of Rust."

The [lecture list](https://web.stanford.edu/class/cs110l/) runs fifteen sessions, ending with "Scalability and Availability" (28 February), "Multithreading Practice" (23 February), and a guest lecture, "What Caused This?" (9 March).
