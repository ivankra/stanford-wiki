# CS 110L: Safety in Systems Programming

Two units taken beside [CS 110](CS%20110.md), and effectively Stanford's Rust course: the catalog frames it as program analysis and robust systems software, and the lectures work through ownership, error handling and concurrency in Rust.

## Syllabus

The catalog states the aim: "Explores how program analysis tools can find common bugs in programs and demonstrates how we can use the Rust programming language to build robust systems software. Course is project-based and will examine additional topics in concurrency and networking through the lens of Rust."

The [lecture list](https://web.stanford.edu/class/cs110l/) runs fifteen sessions, ending with "Scalability and Availability" (28 February), "Multithreading Practice" (23 February), and a guest lecture, "What Caused This?" (9 March).

## Prerequisites

- [CS 110](CS%20110.md) as a corequisite — the course is a supplemental lab to it.
