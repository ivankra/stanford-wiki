# CS 381: Sensorimotor Learning for Embodied Agents

A reading seminar on what separates embodied AI from internet AI: agents that must perceive raw sensory data, act on a physical body, and be improved in hardware as well as software. Half the grade is paper discussion, where each student takes one of seven assigned roles — author, reviewer, learner and so on — and half is a research capstone.

## Syllabus

[The schedule](https://docs.google.com/spreadsheets/d/1xuBI-4IRySSItPuLHrCZztc3tghlH9k6OX9blX5vvdM/htmlembed) alternates Song's lectures with student-led discussions on a set paper.

1. Perception: visual representations for embodied AI, 3D representation (Dense Object Nets, DINOv2), visual affordance for actions.
2. Simulation: simulation environments and sim2real, transferring contact-rich assembly (IndustReal) and agile locomotion.
3. Policies: visuomotor policy learning, implicit behavioral cloning, sample-efficient methods (Perceiver-Actor, Transporter Networks).
4. Embodiment: learning for embodiment design, computational hardware design (RoboGrammar), sensor optimization, sensory data beyond vision, multimodal perception.
5. Frontiers: foundation models for embodied AI, program synthesis for agents (Voyager, Code as Policies), benchmarks and the sim2real gap.

Project proposals land in week 5, presentations in the last session.
