# CS 193X: Web Programming Fundamentals

The deliberately unframeworked web course: HTML, CSS, JavaScript and the DOM written directly, where [CS 142](CS%20142.md) goes on to frameworks and servers. Assignments come in numbered pairs, each graded on separate functionality and style scales.

## Materials

The lectures aren't recorded for anyone — "due to the room and setup" — and everything else the course hands students is on the open site, decks and lecture code included, though those sit in a directory the schedule never links.

- **Syllabus**: the [lectures and schedule page](https://web.stanford.edu/class/cs193x/lectures.html) and the [course-info page](https://web.stanford.edu/class/cs193x/info.html), which gives the grading buckets (`+`, `ok`, `-`, `--`, graded on functionality and style equally), the 70/30 split between assignments and project, the on-time bonus and the collaboration policy.
- **Slides**: a deck per lecture in the [`lectures/`](https://web.stanford.edu/class/cs193x/lectures/) tree, 19 numbered directories each holding `NN-slides.pdf`.
- **Notes**: a single-page [reference](https://web.stanford.edu/class/cs193x/reference.html) covering the HTML, CSS, JavaScript and DOM the course uses.
- **Videos**: none; the room can't record.
- **Assignments**: the [assignment list](https://web.stanford.edu/class/cs193x/assignments.html) runs from a warm-up through JavaScript fundamentals, the Task Board in JavaScript and then restyled in CSS, and a social-media app with its backend. Feedback came back on Paperless, which is not public.
- **Solutions**: none posted; the course grades on written feedback rather than a key.
- **Exams**: none; the grade is assignments and the final project.
- **Projects**: the [final-project brief](https://web.stanford.edu/class/cs193x/project/) and its milestones are public, though no student project is.
- **Repo**: most lecture directories carry `lectNN_start.zip`, the state the lecture begins from, and `lectNN.zip`, where it ends.

## Syllabus

No dated topic list is published beyond the lectures page. The catalog frames the course as the fundamentals of web programming for students who have done [CS 106B](CS%20106B.md); the site's announcements show the rhythm — paired assignments (2.1 and 2.2, 3.1 and 3.2) with feedback on "functionality and style buckets", then a final project reviewed at the end of the quarter.

## Prerequisites

- [CS 106B](CS%20106B.md) or equivalent.

## Related

- [CS 142](CS%20142.md): the full-stack course, which assumes this material and adds frameworks, servers and databases.
- [CS 193C](CS%20193C.md): the summer client-side course covering similar ground.
