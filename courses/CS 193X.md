# CS 193X: Web Programming Fundamentals

The deliberately unframeworked web course: HTML, CSS, JavaScript and the DOM written directly, where [CS 142](CS%20142.md) goes on to frameworks and servers. Assignments come in numbered pairs, each graded on separate functionality and style scales.

## Materials

Everything is public, though the decks and lecture code sit in a directory the schedule never links.

- **Syllabus**: the [lectures and schedule page](https://web.stanford.edu/class/cs193x/lectures.html), plus a course-info page.
- **Notes**: a [reference page](https://web.stanford.edu/class/cs193x/reference.html).
- **Assignments**: the [assignment list](https://web.stanford.edu/class/cs193x/assignments.html).
- **Projects**: the [final-project brief](https://web.stanford.edu/class/cs193x/project/).
- **Slides**: a deck per lecture in an unlinked [`lectures/`](https://web.stanford.edu/class/cs193x/lectures/) tree, numbered `01` to `19`, each directory holding `NN-slides.pdf`.
- **Code**: most of those directories also carry `lectNN_start.zip`, the state the lecture begins from, and `lectNN.zip`, where it ends.
- **Videos**, **Solutions**: not found. **Exams**: none.

## Syllabus

No dated topic list is published beyond the lectures page. The catalog frames the course as the fundamentals of web programming for students who have done [CS 106B](CS%20106B.md); the site's announcements show the rhythm — paired assignments (2.1 and 2.2, 3.1 and 3.2) with feedback on "functionality and style buckets", then a final project reviewed at the end of the quarter.

## Prerequisites

- [CS 106B](CS%20106B.md) or equivalent.

## Related

- [CS 142](CS%20142.md): the full-stack course, which assumes this material and adds frameworks, servers and databases.
- [CS 193C](CS%20193C.md): the summer client-side course covering similar ground.
