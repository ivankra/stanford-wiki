# CS 212: Operating Systems and Systems Programming

Operating systems in one quarter: lectures from threads through virtual machines, reinforced by the four Pintos kernel projects. The site calls it "effectively an accelerated class combining CS111 and CS112" — for students who have not taken CS 111, typically graduate students, and closed to those who have. Lectures, site and exams are shared with CS 112.

## Materials

All public, and the notes index grants permission to copy and redistribute. Only submission and the attendance check-in are gated.

- **Syllabus**: the [schedule](https://www.scs.stanford.edu/26sp-cs212/sched/), with every topic, reading and deadline.
- **Slides**: [17 lecture decks and 6 section decks](https://www.scs.stanford.edu/26sp-cs212/notes/), each as a PDF, a 6-up print PDF and a LaTeX source tarball, several with C examples.

- **Assignments**: [four project handouts](https://www.scs.stanford.edu/26sp-cs212/labs/project.html) with design-document templates, [Lab 0](https://www.scs.stanford.edu/26sp-cs212/labs/lab0.html) and a [git guide](https://www.scs.stanford.edu/26sp-cs212/labs/git.html).

## Syllabus

Ten weeks, Monday and Wednesday lectures with five Friday sections, from the [schedule](https://www.scs.stanford.edu/26sp-cs212/sched/). Readings are given as "Text: Ch. …" without naming the book.

1. Intro, threads and processes, concurrency, scheduling. Lab 0 due.
2. Virtual memory, hardware then OS techniques; synchronization over two lectures. **HW 1 (Threads)** due.
3. Linking, memory allocation, midterm quiz. **HW 2 (Userprog)** due.
4. I/O and disks, file systems, networking, protection. **HW 3 (VM)** due.
5. Security, virtual machines. **HW 4 (File system)** due; final exam 2026-06-06.

## Prerequisites

None in the catalog. The course's own FAQ expects:

- No prior operating systems course; you must not have taken CS 111 or CS 112, whose material this compresses.
- A strong C background, since the projects are kernel code from week one.
