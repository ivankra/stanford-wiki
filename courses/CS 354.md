# CS 354: Topics in Intractability: Unfulfilled Algorithmic Fantasies

The premise is that NP-hardness has been "an amazingly useful tool for algorithm designers" for 45 years, and that it is not the only one. The course collects the other ways to show a problem resists efficient solution: unconditional lower bounds from query and communication complexity, total search problems and PPAD, the Unique Games conjecture, average-case hardness, and fine-grained reductions. Each week works from one source paper, and students scribe the lectures.

## Syllabus

[Week by week](https://web.stanford.edu/class/cs354/), each from one paper.

1. Query complexity, from Vondrak on submodular maximization.
2. Communication complexity, from Babichenko and Rubinstein on approximate Nash equilibria.
3. PPAD and friends, from Daskalakis-Goldberg-Papadimitriou and Chen-Deng-Teng on computing Nash equilibria.
4. Later weeks: Unique Games, average-case complexity, fine-grained complexity.
