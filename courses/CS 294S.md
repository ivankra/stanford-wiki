# CS 294S: Research Project in Software Systems and Security

Not a lecture course: a remote research placement inside one project. Monica Lam's students build Almond, the Sloan-funded open-source virtual assistant whose skills live in Thingpedia rather than in a vendor's catalog, and the syllabus is a list of research openings — better entity disambiguation, meta-learning new domains, dialogue design beyond simple transactions. The final project is 70% of the grade.

## Materials

The schedule and its lecture decks are public, and so — through an unlinked directory the schedule never points at — is the whole of the student project work.

- **Syllabus**: the [schedule](https://web.stanford.edu/class/cs294s/) gives each session with suggested readings (the Almond, Genie, Schema2QA and AutoQA papers), deadlines, and the grading split — participation 15%, homework 15%, final project 70%.
- **Slides**: seven staff decks in the [slides directory](https://web.stanford.edu/class/cs294s/slides/) — the [course introduction](https://web.stanford.edu/class/cs294s/slides/CS294-2020fall.pdf), an NLP overview and ML-for-NLP primer, dialogue, Genie multi-turn, confidence modeling, Schema2QA and "building the best virtual assistant".

## Syllabus

Autumn 2020 ran on the premise that neural dialogue agents can now be generated from a knowledge base without hand-written dialogue trees, and organized its openings into four areas ([site](https://web.stanford.edu/class/cs294s/)):

1. **End-to-end projects**: the ten commonest assistant skills — music, radio, news, sports, podcasts, question answering, weather, timers, IoT control, third-party skills — aiming to match commercial assistants by June 2021.
2. **NLP**: entity disambiguation, naturalness of agent responses, meta-learning new domains, dialogues that recover from mistakes, localization by machine translation.
3. **HCI**: crowdsourcing skills, ontologies and multilingual data from a user community; multimodal interfaces that let end users program long-tail skills.
4. **Systems**: representing well-known data types such as time and space in ThingTalk; extending dialogue models from transactions to FAQs and on-topic discussion.

Lectures cover the group's own papers; the rest of the quarter is pitches, checkpoints and project work.
