# CS 344: Topics in Computer Networks

"This class could also be called 'Build an Internet Router'." Teams of two write a control plane in C on a Linux host and a data plane in P4, and the midterm milestone is not a paper but a demonstration: every team's router must interoperate with every other team's, wired into a small datacenter topology. The last three or four weeks are an open-ended design challenge.

## Syllabus

From the catalog description; no public syllabus.

1. Build the control plane of an Internet router in C, running on a Linux host.
2. Build the data plane in P4, targeting both a software switch and a high-speed hardware switch.
3. Midterm milestone: demonstrate interoperability with the other teams' routers by assembling a small-scale datacenter topology.
4. Final three to four weeks: an open-ended design challenge.

**The hardware target changed between the two offerings.** Spring 2020 used the NetFPGA 4×10GE switch; Spring 2021 names a software switch and a high-speed hardware switch such as the Intel Tofino.

## Prerequisites

- At least one student in each team must have taken [CS 144](CS%20144.md) at Stanford and completed Lab 3, the static router.
- No Verilog or FPGA programming experience is required.

The course may be repeated for credit.
