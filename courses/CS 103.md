# CS 103: Mathematical Foundations of Computing

The proofwriting course and the theory course in one: half a quarter of logic, sets, functions and graphs, then automata, Turing machines and complexity, with ten weekly problem sets carrying most of the grade.

## Materials

Everything except the recordings is public: syllabus, dated schedule, slide decks, written lecture summaries, problem sets and their starter code.

- **Syllabus**: [policies, grading and units](https://cs103.stanford.edu/syllabus); the dated schedule is a public [Google Sheet](https://docs.google.com/spreadsheets/d/1TmqX8wAUToDCSm3Szw0IZjemeiEzSRDn/edit).
- **Slides**: each lecture page carries a full and a condensed PDF deck — [lecture 0](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/lectures/00/) through lecture 2 so far, released as the quarter runs.
- **Notes**: a written summary with every lecture, plus standing guides — [Guide to Proofs](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/guide_to_proofs), [Proofwriting Checklist](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/proofwriting_checklist), [Guide to LaTeX](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/guide_to_latex) and [elements vs subsets](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/elements_and_subsets).
- **Videos**: Panopto through Canvas; no public recordings.
- **Assignments**: [Problem Set 0](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/psets/ps0/) (environment setup) and [Problem Set 1](https://web.stanford.edu/class/archive/cs/cs103/cs103.1272/psets/ps1/) (proofs and set theory), with a LaTeX template; ten in total.
- **Exams**: the Exams section is still empty; a midterm (Oct 19) and final (Dec 9) are on the schedule.
- **Projects**: none.
- **Code**: Qt Creator starter projects ship with the problem sets.

## Syllabus

The [schedule](https://docs.google.com/spreadsheets/d/1TmqX8wAUToDCSm3Szw0IZjemeiEzSRDn/edit) runs ten weeks, one problem set a week:

1. **Weeks 1–4, proof and structure**: set theory, mathematical and indirect proofs, propositional logic, first-order logic, functions, set theory revisited, graphs.
2. **Week 5**: midterm, then mathematical induction.
3. **Weeks 6–7, languages**: finite automata, regular expressions, nonregular languages, context-free languages.
4. **Weeks 8–9, computability**: Turing machines, unsolvable problems.
5. **Week 10**: complexity theory and P versus NP.

Proofs must be typed, and are graded against the course's own proofwriting checklist as well as for correctness.

## Prerequisites

- Programming: [CS 106B](CS%20106B.md) or CS 106X, which may be taken **concurrently**. The C++ problems assume recursion at [CS 106B](CS%20106B.md)'s level, and are timed to follow it.
- Mathematics: high-school algebra only. Everything else is built up in the course.
