# CS 273A: The Human Genome Source Code

The conceit is carried the whole way: genes are variable assignments, gene regulation is control flow, epigenomics is the run-time stack, disease is a hunt for bugs, and genome editing is code injection. No biological background is assumed — the course supplies primers on molecular biology and on text-processing languages — and the algorithms come from computational genomics, machine learning and NLP. The Winter 2021 description sharpens the pitch: "Handling genomic data is deceptively easy. But that's muscle. You want to be the brain, too."

## Materials

The site is generous with the teaching and closed about the coursework: every deck and every set of lecture notes is in an open directory, and the course records nothing for anybody, so a reader gets the lectures on the same terms an enrolled student does. The homework goes out on Piazza, and the tools it needs sit on an AFS path only Stanford machines can reach.

- **Syllabus**: the [course page](https://web.stanford.edu/class/cs273a/cgi-bin/index.php) — a dated 20-session schedule, three primer sessions (biology, text processing, the UCSC genome browser), the grading split (4 homeworks at 15% each, final at 40%), late days, the honor code and a bibliography.
- **Slides**: [16 decks](https://web.stanford.edu/class/cs273a/presentations/lecture1.pptx) as PowerPoint, one per lecture, in a browsable directory.
- **Notes**: [16 notes PDFs](https://web.stanford.edu/class/cs273a/presentations/gill0v1_notes.pdf) in the same directory — 13 lecture sets plus the three primers.
- **Videos**: none. The offering ran on Zoom and the site states "no attendance taken, but lectures will not be recorded".
- **Assignments**: closed. The schedule's HW column links nothing, and "course announcements and other private course resources will be communicated via Piazza". **Winter 2020** is the exception: 2 of its 4 handouts, [hw1](https://web.stanford.edu/class/cs273a/hw/hw1.pdf) and [hw2](https://web.stanford.edu/class/cs273a/hw/hw2.pdf), sit in an unlinked `hw/` directory.
- **Solutions**: not found. **Exams**: the take-home final, worth 40%, is not posted. **Projects**: none.
- **Repo**: closed. The course's executables live in `/afs/ir.stanford.edu/class/cs273a`, reachable only from Stanford's `cardinal`, `myth` and `rice` machines, so the homework cannot be run from outside even where the handout is public.
- **Older offerings**: the site keeps a page per offering back to Spring 2007 — 14 of them, each with its own schedule, including [Winter 2020](https://web.stanford.edu/class/cs273a/win2020.html).

## Syllabus

From the catalog description; no public syllabus.

1. Genome sequencing: assembling source code from code fragments.
2. The human genome's functional landscape — variable assignments (genes), control-flow logic (gene regulation), run-time stack (epigenomics).
3. Human disease and personalized genomics, as a hunt for bugs in the human code.
4. Genome editing — code injection — to cure the incurable.
5. The source-code modifications behind animal adaptations.
6. Primers on molecular biology and on text-processing languages, run alongside.
