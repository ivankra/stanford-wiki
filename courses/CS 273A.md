# CS 273A: The Human Genome Source Code

The conceit is carried the whole way: genes are variable assignments, gene regulation is control flow, epigenomics is the run-time stack, disease is a hunt for bugs, and genome editing is code injection. No biological background is assumed — the course supplies primers on molecular biology and on text-processing languages — and the algorithms come from computational genomics, machine learning and NLP. The Winter 2021 description sharpens the pitch: "Handling genomic data is deceptively easy. But that's muscle. You want to be the brain, too."

## Materials

The site is generous with lectures and closed about coursework: every deck and every set of lecture notes is downloadable, and the four homeworks and the take-home final are not.

- **Syllabus**: the [course page](https://web.stanford.edu/class/cs273a/cgi-bin/index.php) — a dated twenty-session schedule, three primer sessions (biology, text processing, the UCSC genome browser), the grading split (four homeworks at 15%, final at 40%), late days, the honor code and a bibliography.
- **Slides**: [sixteen decks](https://web.stanford.edu/class/cs273a/presentations/lecture1.pptx) as PowerPoint, one per lecture.
- **Notes**: a [PDF per lecture](https://web.stanford.edu/class/cs273a/presentations/gill0v1_notes.pdf) beside each deck, primers included.
- **Videos**: none. The Winter 2021 offering ran on Zoom and the site states "lectures will not be recorded".
- **Assignments**: the schedule's HW column links nothing and "course announcements and other private course resources will be communicated via Piazza" — but two of the four handouts, [hw1](https://web.stanford.edu/class/cs273a/hw/hw1.pdf) and [hw2](https://web.stanford.edu/class/cs273a/hw/hw2.pdf), sit in an unlinked `hw/` directory, dated January and February 2020. **Exams**: the take-home final is not posted.
- **Code**: the course's executables live in `/afs/ir.stanford.edu/class/cs273a`, reachable only from Stanford's `cardinal`, `myth` and `rice` machines.
- **Extra**: the site keeps a page per offering back to Spring 2007 — fourteen of them, each with its own schedule and decks.

## Syllabus

From the catalog description; no public syllabus.

1. Genome sequencing: assembling source code from code fragments.
2. The human genome's functional landscape — variable assignments (genes), control-flow logic (gene regulation), run-time stack (epigenomics).
3. Human disease and personalized genomics, as a hunt for bugs in the human code.
4. Genome editing — code injection — to cure the incurable.
5. The source-code modifications behind animal adaptations.
6. Primers on molecular biology and on text-processing languages, run alongside.
