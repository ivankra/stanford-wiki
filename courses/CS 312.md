# CS 312: Deep Learning Alchemy

Deep learning taught as an experimental science: small, tractable models, many runs, and quizzes that ask you to predict what a held-out experiment will do.

## Syllabus

[Syllabus](https://cs312.stanford.edu/#schedule) has seven units. Each runs assignment → 1–2 lectures → weekly tutorial → report → prediction quiz. Units 1–4 use small language models; 5–7 use DNA.

1. Basics: hyperparameter tuning and scaling
2. Optimization 1: hyperparameter invariants
3. Optimization 2: sharp and flat basins
4. Architecture 1: extending model capacity
5. Architecture 2: stability across depth and time
6. Generalization: data-efficient algorithms
7. Exotic: not yet announced

## Prerequisites

The course site expects:

- Calculus and linear algebra: MATH 51 or CME 100.
- Probability and statistics: CS 109 or equivalent.
- Programming: enough Python to follow the provided codebase and short code diffs.

Recommended, not required: prior deep learning ([CS 229](CS%20229.md) or [CS 230](CS%20230.md)); backpropagation and efficient implementation receive little coverage.
