# CS 193V: Effective Vibecoding

A new course that takes its premise literally: students build software "purely using AI-assisted coding tools", with no code reading or writing expected of them, and spend the quarter learning the surrounding craft — version control, testing, deployment, and the security holes AI-written code tends to leave. The syllabus steers CS majors to [CS 146S](CS%20146S.md) instead.

## Syllabus

From the [published breakdown](https://web.stanford.edu/class/archive/cs/cs193v/cs193v.1272/syllabus):

1. **Weeks 1–2, technical foundations**: the command line, git and GitHub, software testing.
2. **Week 3, asking for what you want**: plan mode, iterating on designs, and the basics of user interviews.
3. **Week 4**: data formats, data analysis and visualization, API keys and how to keep them safe.
4. **Weeks 5–6, web applications**: ports, IP addresses and DNS, the client/server model, deployment, style and iteration.
5. **Week 7, working in a team**: issue tracking, pull requests, continuous integration.
6. **Week 8, privacy and security**: containers and virtual machines, zero-days, "the 'Lethal Trifecta'".
7. **Week 9**: mobile development — getting code onto a device, testing and debugging there.

The stated ceiling is part of the argument: current tools "aren't good enough to build large-scale programs autonomously", and AI-written code "frequently contains critical security or privacy holes", which week 8 examines firsthand.
