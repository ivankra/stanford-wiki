# CS 193Q: Introduction to Python Programming

One unit and twelve hours: Python shown to people who already program, feature by feature, up to dictionaries and comprehensions. Everything is due by the end of week 8 and there is nothing else to it.

## Materials

The site is small and entirely public: lecture notes and the code zips, plus a free companion course by the same instructor.

- **Syllabus**: the [one-page site](https://cs193q.stanford.edu/) — scope, format, deadline and grading.
- **Notes**: [lecture 1 notes](https://web.stanford.edu/class/cs193q/lecture-1.html), one page per meeting.
- **Assignments and code**: [code1.zip](https://web.stanford.edu/class/cs193q/code1.zip) carries the lecture examples and the exercises; homework is held until a turn-in link appears "around week 4".
- **Videos**: none of its own; the site recommends the instructor's free [Google Python Class](https://developers.google.com/edu/python), which has videos and exercises "similar niche to this course".
- **Exams**, **Projects**: none.

## Syllabus

No dated schedule. The site sets the scope: "all the important fundamental Python features — up through dictionaries and comprehensions", shown by demonstrating how each familiar programming idea is expressed in Python, with a few programs written along the way. The catalog adds the comparison: the same end point as CS 106AP's — strings, lists, numbers, dicts, loops, logic, functions, testing, decomposition and style, modules — reached in three four-hour meetings instead of a quarter.

## Prerequisites

- Knowledge of some programming language. The course explicitly assumes it, and spends no time on programming fundamentals.
