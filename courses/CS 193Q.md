# CS 193Q: Introduction to Python Programming

One unit and twelve hours: Python shown to people who already program, feature by feature, up to dictionaries and comprehensions. Everything is due by the end of week 8 and there is nothing else to it.

## Materials

The site is small and almost entirely public: a written notes page and a code zip for each meeting, the three graded programs specified on the front page, and a free companion course by the same instructor. The one thing nothing states is whether the Thursday Zoom lectures are recorded.

- **Syllabus**: the [one-page site](https://cs193q.stanford.edu/) — scope, format, the end-of-week-8 deadline, 1 unit pass/no-credit.
- **Slides**: none; each meeting is published as notes instead.
- **Notes**: [lecture 1](https://web.stanford.edu/class/cs193q/lecture-1.html) through lecture 4 so far, each a page of worked examples, with [Parlante's Python Guide](https://cs.stanford.edu/people/nick/py/) as the reference.
- **Videos**: nothing found, and no source says whether the Zoom lectures are recorded.
- **Assignments**: the short exercises ship inside each lecture's [code zip](https://web.stanford.edu/class/cs193q/code1.zip), and the graded programs — Printly, Crypto, and Tiptop or Concordance — are specified on the front page. Turn-in opens "around week 4"; until then "just do them and hold onto them".
- **Solutions**: each zip pairs a worked program with an `-orig` copy, but nothing is labelled a solution.
- **Exams**, **Projects**: none — the three programs are the whole assessment, and "we are not grading the other short exercises".
- **Repo**: one [zip](https://web.stanford.edu/class/cs193q/code1.zip) of examples and exercises per lecture.
- **Textbook**: Lubanovic's *Introducing Python*, recommended and not required.
- **Self-study**: the instructor's free [Google Python Class](https://developers.google.com/edu/python), which the site names as having "videos, exercises, similar niche to this course". It is Python 2 and years old, and it is the only video treatment of this material that anyone, enrolled or not, is pointed at.

## Syllabus

No dated schedule. The site sets the scope: "all the important fundamental Python features — up through dictionaries and comprehensions", shown by demonstrating how each familiar programming idea is expressed in Python, with a few programs written along the way. The catalog adds the comparison: the same end point as CS 106AP's — strings, lists, numbers, dicts, loops, logic, functions, testing, decomposition and style, modules — reached in three four-hour meetings instead of a quarter.

## Prerequisites

- Knowledge of some programming language. The course explicitly assumes it, and spends no time on programming fundamentals.
