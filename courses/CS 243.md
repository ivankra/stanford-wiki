# CS 243: Program Analysis and Optimizations

Monica Lam's compilers course, and the one that treats a compiler as a worked example of a general engineering method rather than as an end in itself: the catalog frames it as "the methodology of applying mathematical abstractions such as graphs, fixpoint computations, binary decision diagrams in writing complex software, using compilers as an example". The optimization half runs from instruction scheduling and register allocation out to loop transformations for parallelism and locality, and then to whole-program interprocedural analysis. It is the analysis counterpart to a first compilers course, which builds the front end.

## Syllabus

From the Winter 2026 schedule, which pairs each lecture with dragon-book chapters.

1. **Data-flow analysis** (lectures 1–4): introduction, the theoretical foundation, then constant propagation and loops. Chapters 9.1–9.4, 9.6.
2. **Classical optimization** (5–7): partial redundancy elimination, register allocation, instruction scheduling. Chapters 9.5, 8.8, 10.1–10.4.
3. **Parallelism and locality** (8–12): software pipelining, parallelization, loop transformations, pipelined parallelism, and locality against parallelism. Chapters 10.5, 11.1–11.11 — the largest single block, five lectures.
4. **Verification** (13–14): SSA form and an introduction to satisfiability modulo theories, then SMT solvers.
5. **Memory and whole programs** (15–16): garbage collection (7.4–7.7.4), pointer analysis (chapter 12).
6. **Automatic coding with LLMs** (17), the course's own answer to its framing question about natural language as the highest-level programming language.

The catalog's summary:

> Program analysis techniques used in compilers and software development tools to improve productivity, reliability, and security. The methodology of applying mathematical abstractions such as graphs, fixpoint computations, binary decision diagrams in writing complex software, using compilers as an example. Topics include data flow analysis, instruction scheduling, register allocation, parallelism, data locality, interprocedural analysis, and garbage collection.

## Prerequisites

- Discrete mathematics and proof: [CS 103](CS%20103.md) or CS 103B — the analyses are defined over lattices and argued by fixpoint reasoning.
- Systems programming: [CS 107](CS%20107.md).

A first compilers course is not required; this one starts at the intermediate representation.
