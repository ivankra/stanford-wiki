# CS 41: Hap.py Code: The Python Programming Language

Four weeks of language, then six of applications chosen for variety — electronics, web APIs, low-level Python, gaming — and a month on a personal project. Two units, S/NC, with almost everything published.

## Materials

Slides and code for most sessions, every assignment spec, and one lab's solutions.

- **Syllabus**: the [site](https://stanfordpython.com/) — a week-by-week lecture table and an assignment table with due dates.
- **Slides**: a deck beside most sessions.
- **Notes**: per-session scratchpads and an API resource sheet.
- **Assignments**: specs for a0 through a3, the install-python handout and the lab material.
- **Solutions**: published for lab 2 only.
- **Code**: linked beside most lectures — snake and circle games, micro:bit wifi, server-side examples.
- **Videos**: not found. **Exams**: none.

## Syllabus

From the [lecture table](https://stanfordpython.com/), the course's own summary of its shape: "The first two weeks cover the basics of programming in Python (loops, control flow, functions, etc.). The next two weeks cover extending Python through custom objects, decorators. Along the way, it covers different programming philosophies like object-oriented and functional programming. The second half of the course is topics-based, and generally covers creating websites in Python, robotics, and data science. For the last month, every student completes a significant, personal final project in Python."

The Spring 2023 second half ran: data structures and object-oriented Python, electronics, web APIs, server-side Python, low-level Python, functions and functional programming, standard and third-party libraries, and gaming.
