# CS 41: Hap.py Code: The Python Programming Language

Four weeks of language, then six of applications chosen for variety — electronics, web APIs, low-level Python, gaming — and a month on a personal project. Two units, S/NC, with almost everything published.

## Materials

Almost everything is published, and all of it on the course's own host: the schedule with a paragraph per session, a deck for most lectures, the code each one used, every assignment spec and the syllabus page. What is missing is recordings, which nothing says were made, and solutions, of which exactly one set is posted.

- **Syllabus**: the [site](https://stanfordpython.com/) carries a week-by-week lecture table with a description of each session and an assignment table with due dates; the [syllabus page](https://stanfordpython.com/#/page/syllabus) adds the honor-code and accommodation policies.
- **Slides**: [12 lecture PDFs](https://stanfordpython.com/lecture/1-intro.pdf) on the site, from the introduction through classes, electronics, standard libraries and gaming.
- **Notes**: a [resource document](https://docs.google.com/document/d/1Mp5qxBuqGc9AbjIg2yStiR1ahD6kl4esXMhrDpmx6Xw/edit) linked from the lecture table; a second lecture document beside it answers 401.
- **Videos**: not found. The "playlist" the landing page links is a Spotify playlist, not recordings.
- **Assignments**: [a0](https://stanfordpython.com/#/page/assignment-0) and a1 are pages on the site, a2 (in two parts, a sketch and a final artifact) and a3 (the final project, proposal and all) are public Google Docs, and there is an install-python handout. Submission ran through Stanford's paperless system, and the section sign-up sheet answers 401.
- **Solutions**: lab 2's only. Nothing else has a key.
- **Exams**: none; the final project replaces one.
- **Projects**: the proposal and spec are public, but no student work is.
- **Repo**: [7 per-lecture code archives](https://stanfordpython.com/lecture/2-code.zip) and loose scripts — the snake and circle games, micro:bit wifi, server-side and Axess examples.

## Syllabus

From the [lecture table](https://stanfordpython.com/), the course's own summary of its shape: "The first two weeks cover the basics of programming in Python (loops, control flow, functions, etc.). The next two weeks cover extending Python through custom objects, decorators. Along the way, it covers different programming philosophies like object-oriented and functional programming. The second half of the course is topics-based, and generally covers creating websites in Python, robotics, and data science. For the last month, every student completes a significant, personal final project in Python."

The Spring 2023 second half ran: data structures and object-oriented Python, electronics, web APIs, server-side Python, low-level Python, functions and functional programming, standard and third-party libraries, and gaming.
