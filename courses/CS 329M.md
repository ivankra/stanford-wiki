# CS 329M: Machine Programming

How to build real-world machine programming (MP) systems, which automate software development. Lectures survey the field and its foundations, including why learning from code differs from other ML (self-supervision on open-source code; static, dynamic and specification-based signals), while students spend nine weeks building and demoing their own MP system.

## Syllabus

One three-hour lecture a week:

1. Fundamentals of machine programming
2. Tour of the state of MP: Claude Code, GitHub Copilot, Cursor, Devin Desktop, Replit Agent and others
3. Core tenets and first principles of ML and MP
4. Principles of data: ground truth, semi-trust, static and continuous learning
5. Meta-data, meta-reasoning, latent spaces and higher-dimensional analyses
6. Performance implications of MP: cloud, local, hybrid
7. Classical and future software engineering with temporal reasoning
8. Future of programming and programming languages (HIPLs, MIPLs, intentional PLs)
9. Future of MP and the next decade

Week 1–2 readings include *Three Pillars of Machine Programming* and SWE-bench.

## Prerequisites

None listed. Aimed at MS and PhD students; the site says senior undergraduates have completed it and that students new to ML, PL, SE and systems have done well.
